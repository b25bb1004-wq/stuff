## Public API (exact)
```rust
// cobalt::rv64
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum CodegenError { Unsupported(String), NoEntry(String) }
pub fn emit_asm(p: &logos::ir::Program, entry: &str) -> Result<String, CodegenError>; // chisel source
pub fn compile_elf(p: &logos::ir::Program, entry: &str) -> Result<Vec<u8>, CodegenError>;

```
`run` is behind `#[cfg(any(test, feature = "silicon"))]` only if `silicon` must stay a dev-dependency;
otherwise make `silicon` an optional feature named `silicon` that the tests enable.

## Subset (exact)
- Supported: functions whose parameters and result are `Int` or `Bool` (and `Unit` result), the
  instructions `Lit` (Int, Bool, Unit), `Move`, `Un` (neg, not), `Bin` (+ - * / % == != < <= > >=
  and or, as Logos defines them for Int and Bool), `Call` (direct, any depth, recursion),
  `Label`, `Jump`, `Branch`, `Ret`, `Assert`. Anything else, or any other type, gives
  `Unsupported(<what>)` naming the instruction or type; never a panic.
- `entry` names a function with no parameters returning `Int`; else `NoEntry(entry)`.
- Scheme: every IR register gets an 8-byte stack slot in its function's frame; arguments in
  a0..a7 (more than 8 parameters: Unsupported), result in a0, ra and the frame saved as usual.
- Traps exactly as the Elysium interpreter traps: Int overflow on + - * and neg (i64), divide or
  remainder by zero, `i64::MIN / -1`, failed `Assert`, and call depth above 10_000 (stack overflow).
- Start-up: `_start` sets sp to the top of RAM, calls `entry`, prints the result in decimal with a
  trailing `\n` on the UART, then writes Pass to the test finisher. A trap prints `trap <n>\n`
  and writes `Fail(n)`: overflow 1, divide by zero 2, assert 3, stack overflow 4.

## Tests required
`tests/rv64.rs`: at least 25 Logos programs (fib, gcd, factorial with overflow, loops, nested calls,
mutual recursion, every trap, short-circuit and/or, Bool results through Int) run with `run` and
compared with `cobalt::run_main` / the Elysium result; every unsupported construct named.

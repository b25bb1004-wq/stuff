The crate is `#![cfg_attr(not(test), no_std)]` with `extern crate alloc;`.

This is the first slice of the Strata CPU emulator: the unprivileged RISC-V RV64I base set plus
the M extension. No CSRs, privilege modes, paging, compressed or atomic instructions yet; a later
task adds them, so keep `step` small and the instruction enum easy to extend.

## Public API (exact)
```rust
pub enum Fault { Unmapped(u64), Misaligned(u64) }                  // Debug, Clone, Copy, PartialEq, Eq
pub trait Bus {
    fn read(&mut self, addr: u64, size: u8) -> Result<u64, Fault>;   // size is 1, 2, 4 or 8; little endian; zero-extended
    fn write(&mut self, addr: u64, size: u8, value: u64) -> Result<(), Fault>;
}
pub struct Ram;                                                    // impl Bus; new(base: u64, size: usize); load(&mut self, addr, &[u8]) -> Result<(), Fault>
pub enum Trap {                                                    // Debug, Clone, Copy, PartialEq, Eq
    IllegalInstruction(u32), Ecall, Ebreak,
    FetchFault(u64), LoadFault(u64), StoreFault(u64), FetchMisaligned(u64),
}
pub mod inst {
    pub enum Inst { .. }                 // one variant per instruction, fields rd/rs1/rs2: u8, imm: i64. Debug, Clone, Copy, PartialEq, Eq
    pub fn decode(word: u32) -> Option<Inst>;
    pub fn encode(inst: Inst) -> u32;    // exact inverse of decode for every valid Inst
}
pub struct Cpu { pub x: [u64; 32], pub pc: u64, pub instret: u64 }
impl Cpu {
    pub fn new(pc: u64) -> Cpu;
    pub fn step(&mut self, bus: &mut impl Bus) -> Result<(), Trap>;  // one instruction; on Err the pc and registers are unchanged
    pub fn run(&mut self, bus: &mut impl Bus, max_steps: u64) -> Result<(), Trap>; // Ok if max_steps ran without a trap
}
```
Rules: `x[0]` always reads 0. Jumps and taken branches to a pc that is not a multiple of 4 trap
with `FetchMisaligned(target)`. Loads and stores may be unaligned (the Bus decides).
`Ram` returns `Unmapped` for any access not fully inside `base..base+size`. `FENCE` is a no-op.

## Instructions
RV64I: LUI AUIPC JAL JALR, BEQ BNE BLT BGE BLTU BGEU, LB LH LW LD LBU LHU LWU, SB SH SW SD,
ADDI SLTI SLTIU XORI ORI ANDI SLLI SRLI SRAI (6-bit shamt), ADD SUB SLL SLT SLTU XOR SRL SRA OR
AND, ADDIW SLLIW SRLIW SRAIW ADDW SUBW SLLW SRLW SRAW, FENCE, ECALL, EBREAK.
M: MUL MULH MULHSU MULHU DIV DIVU REM REMU, MULW DIVW DIVUW REMW REMUW.
Division by zero and signed overflow follow the RISC-V specification exactly (DIV by 0 gives
-1, REM by 0 gives the dividend, MIN / -1 gives MIN with remainder 0; same for the W forms).

## Tests required
- `decode(encode(i)) == Some(i)` for random valid instructions of every variant (`forall`).
- `decode` never panics on any `u32` (`forall` over random words) and rejects all-zero and
  all-one words.
- Every instruction: at least one directed test, plus property tests against plain Rust
  arithmetic (wrapping ops, `i128` for MULH forms, sign extension of every W result).
- Edge cases above for DIV/REM; shifts by 0, 63 and 31 (W); JALR clears bit 0 of the target;
  writes to x0 are discarded; a failed step leaves pc, registers and instret unchanged.
- Loads sign or zero extend correctly for each width; store then load round trip (`forall`).
- Two whole programs built with `inst::encode` and run on `Ram`: iterative Fibonacci(50) and a
  bubble sort of 16 random u64 values in memory, each ending in `EBREAK`.

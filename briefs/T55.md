## Public API (crate root, exact)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Key { Char(char), Ctrl(char), Enter, Esc, Backspace, Delete, Tab, Left, Right, Up, Down,
    Home, End, PageUp, PageDown }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Mode { Normal, Insert, Command, Search }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Style { Plain, Keyword, Type, Number, String, Comment, Error, Status, Match }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Screen { pub rows: Vec<String>, pub styles: Vec<Vec<Style>>, pub cursor: (usize, usize) }
pub struct App;
impl App {
    pub fn new(width: usize, height: usize) -> App;                 // scratch buffer, no name
    pub fn with_text(name: &str, text: &str, width: usize, height: usize) -> App;
    pub fn open(path: &std::path::Path, width: usize, height: usize) -> std::io::Result<App>;
    // name = path.display(); a missing file opens as an empty, unmodified buffer
    pub fn handle(&mut self, key: Key);
    pub fn render(&mut self) -> Screen;
    pub fn text(&self) -> String;
    pub fn cursor(&self) -> (usize, usize);   // (line, column in chars), both from 0
    pub fn mode(&self) -> Mode;
    pub fn modified(&self) -> bool;
    pub fn quit_requested(&self) -> bool;
    pub fn resize(&mut self, width: usize, height: usize);
}
pub fn highlight(name: &str, text: &str) -> Vec<Style>; // one per byte of text
pub fn parse_keys(s: &str) -> Vec<Key>;  // test notation, below
pub fn decode_keys(bytes: &[u8]) -> Vec<Key>; // terminal input bytes
pub fn ansi(screen: &Screen) -> String;  // full-screen redraw with escape sequences
```
`parse_keys`: `<Esc> <CR> <BS> <Del> <Tab> <Left> <Right> <Up> <Down> <Home> <End> <PgUp> <PgDn>`,
`<C-x>` = `Ctrl('x')`, `<lt>` = `Char('<')`; every other char is `Char`. `decode_keys`: printable
UTF-8 = `Char`, 13 = Enter, 27 alone = Esc, 127 and 8 = Backspace, 9 = Tab, 1..=26 others =
`Ctrl(letter)`, `ESC [ A/B/C/D` = Up/Down/Right/Left, `ESC [ H`/`ESC [ F` = Home/End, `ESC [ 3 ~`
Delete, `ESC [ 5 ~`/`6 ~` PageUp/PageDown; unknown sequences are dropped. `ansi`: `ESC[H`, then
each row with SGR colours per style run and `ESC[0m` at the end of each row joined by `\r\n`,
then `ESC[{row+1};{col+1}H` for the cursor (exact colours are free).

## Text
The buffer is the text split on `\n` (one line when empty); `text()` joins the lines with `\n`,
so files read and write byte-exact (a trailing newline is a last empty line). No other byte is
special.

## Normal mode (counts: a decimal prefix repeats the command; `0` alone is a motion)
- `h l Left Right`: within the line; `j k Down Up`: line +-1 keeping a sticky column (set by any
  horizontal move); `0 Home` line start, `$ End` last char; `w`/`b`: next/previous word start, a
  word being a run of `[A-Za-z0-9_]` or a run of other non-blank chars, crossing lines, an empty
  line counting as a word; `gg` first line, `G` last line, `{n}G` line n, all three to the first
  non-blank. `PageDown`/`PageUp`: move by (text rows - 1) lines.
- The cursor in Normal mode sits on a char: column `<= len - 1` (0 on an empty line).
- `x` delete char(s) under the cursor; `dd` delete line(s); `yy` yank line(s); `p`/`P` paste
  after/before (a line-wise register pastes below/above the current line and puts the cursor on
  the first non-blank of the first pasted line; a char-wise one pastes after/at the cursor and
  leaves it on the last pasted char). `x` and `dd` fill the register. `dd` on the only line
  leaves one empty line.
- `i a I A o O` enter Insert (before cursor, after cursor, first non-blank, end of line, new line
  below, new line above). `u` undo, `Ctrl('r')` redo: one step per Normal command and per whole
  Insert session (a `:s`/`:%s` command is one step too); a command or session that changes nothing
  adds no step; the cursor goes to the start of the changed text (clamped onto a char).
- `/` Search mode, `:` Command mode. `n`/`N` repeat the last search forward/backward (wrapping):
  forward = first match starting after the cursor, backward = last match starting before it.
  Unknown keys do nothing.

## Insert, Search and Command modes
- Insert: chars insert at the cursor, `Enter` splits the line (no auto-indent), `Tab` inserts
  `\t`, `Backspace` deletes before the cursor (joins lines at column 0, nothing at the very
  start), `Delete` deletes under it (joins with the next line at line end), arrows move (the
  cursor may sit after the last char). `Esc` back to Normal with the cursor moved one left
  (not past column 0).
- Search: typed chars edit the pattern shown on the last row as `/pattern`; `Backspace` on an
  empty pattern or `Esc` cancels; `Enter` finds the next match of the calliope `Regex` after the
  cursor, wrapping to the top; the cursor goes to the match start; no match: message
  `no match: {pattern}`; bad pattern: `bad regex`.
- Command (`:text`, edited like Search; `Enter` runs it): `w`, `w path`, `q` (refused with
  `unsaved changes (use :q! to quit)` when modified), `q!`, `wq`, `e path`, `{n}` go to line n,
  `s/re/rep/` and `s/re/rep/g` on the current line, `%s/re/rep/` and `%s/re/rep/g` on every line
  (first match per line without `g`); `\/` is a literal `/` in either part; `rep` is literal.
  `{n}` goes to the first non-blank of line n. `w path` writes there without renaming the buffer.
  `e path` is refused with the unsaved-changes message when modified; otherwise it loads the file
  as `open` does (cursor (0, 0), new name). `path` is the rest of the text after one space.
  Messages: `wrote {n} bytes`, `cannot write: {path}`, `{n} substitutions`, `no match: {re}`,
  `bad regex`, `unknown command: {text}`. Saving clears `modified`.

## Screen
- `height - 1` text rows then the status row; every row is exactly `width` chars (padded with
  spaces, cut when longer; rows past the last line are all spaces). Tabs show as spaces to the
  next multiple of 4 (a tab at column 4 takes 4). No wrapping: the view
  scrolls vertically and horizontally just enough to keep the cursor visible.
- Status row (style `Status`): `{NORMAL|INSERT} {name}{ [+] if modified} {line+1}:{col+1}`
  with name `[scratch]` when unnamed; in Search/Command mode it is `/pattern` or `:text` with the
  cursor after it; a message replaces it for the next render only.
- Text cells take `highlight` styles; the matches of the last search pattern on screen show as
  `Match`. `cursor` is the screen position (row, column).

## Highlighting
`highlight(name, text)`: Plain for everything unless `name` ends with `.logos`. Then from
`logos::lexer::lex` (comments are skipped, not tokens): tokens whose source text is all `[a-z_]` and is not an `LIdent` = Keyword, `UIdent`
= Type, `Int` and `Byte` = Number, `Str` = String, `//` to the end of the line = Comment, the rest
Plain. If `lex` fails: the error span to the end of its line is Error, and only the text before
the span is highlighted as above (lex that prefix).

## Tool
- `aurum`: `keygen -o KEYFILE` (prints address), `tx KEYFILE TO AMOUNT NONCE -o TX` (signed transfer in the library encoding, hex file), `merkle FILE...` (root of the files' sha256 leaves, and with `--proof N` the proof), `verify CHAIN` (validate a chain file in the library encoding, exit 1 with the first bad block), `demo -o CHAIN` (builds the same 3-block demo chain the site uses, so `verify` has input). No network subcommand (deploy's `aurum-node` covers it).

## Tests
`tests/cli_aurum.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input
each (exit 1 and a `aurum:` message), an unknown subcommand (exit 2). Run `cargo fmt -p aurum` before the gate.

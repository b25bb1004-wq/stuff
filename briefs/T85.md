- Activity bar 48 px, three icon buttons (inline SVG, `aria-label`, `aria-pressed`): Explorer, Search, Testing.
  Clicking the active one collapses the sidebar (Ctrl+B too).
- Search view: input; results grouped by file, each line `Ln N: text` with the match marked; clicking opens the
  file at that position.
- Editor tabs: open files as tabs, `*` or a dot when unsaved, close button, middle-click closes, Ctrl+W closes,
  Ctrl+Tab / Ctrl+Shift+Tab cycle, Ctrl+S saves. Open tabs and the active one persist in localStorage
  (`athena.tabs.v1`). Closing an unsaved tab asks in an inline bar (Save / Discard / Cancel), never `confirm()`.
- Command palette: Ctrl+Shift+P (and F1) opens a centred overlay listing every command with its shortcut
  (Run, Test, Format, New File, Save, Close Tab, Toggle Panel, Toggle Sidebar, Toggle Theme, Go to Definition,
  Show Hover, Focus Terminal, Install App); typing filters by subsequence match, arrows move, Enter runs, Esc
  closes. Ctrl+P opens the same overlay in file mode (quick open). Focus is trapped while open and returns after.
- Panel: Problems lists every diagnostic of the open files (click jumps); Output, Tests, Terminal as now.
- Status bar: wasm state, file name, caret `Ln, Col` (updates on move), problem count (click opens Problems),
  language. Mobile (under 720 px): activity bar becomes a bottom tab strip (Files, Search, Editor, Panel), sidebar
  and panel become full-screen views, palette still works.
- Code split: `web/athena.js` (wasm glue, editor, language features), `web/workbench.js` (activity bar, tabs,
  palette, panel, status bar), ES modules (`<script type="module">`). Each file at most about 900 lines.

## Installable app (PWA)
- `web/manifest.webmanifest`: name `Athena`, short_name `Athena`, `display: "standalone"`,
  `display_override: ["window-controls-overlay", "standalone"]`, `start_url: "./"`, `scope: "./"`, theme and
  background `#0e1013`, icons 192 and 512 PNG plus a maskable 512. All paths relative (the app is served at
  `/athena/` on the public site).
- Icons: `pack` draws them with pigment (`--bg` square, an amber `--accent` capital-A-like mark from rectangles and
  triangles, maskable one with 20% safe padding) and writes `icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png`.
- `web/sw.js`: on install caches every bundle file (list written by `pack` into the file as a JSON array, plus a
  cache name with a content hash of the bundle, so a new deploy replaces the cache); fetch is cache-first for
  same-origin GET, falls back to network; old caches deleted on activate. Registered from `athena.js` only when
  `navigator.serviceWorker` exists.
- Install: listen for `beforeinstallprompt`; show an "Install" button in the title area and the palette command;
  hide it when `display-mode: standalone` matches. In window-controls-overlay mode the title area uses
  `env(titlebar-area-*)` so the tab bar sits in the window's title bar like a desktop app.

## indium::anim (exact)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Ease { Linear, InQuad, OutQuad, InOutQuad, OutCubic }
pub fn ease(e: Ease, t: u32) -> u32;   // t clamped to 0..=1000; result in 0..=1000
pub fn tween(from: i32, to: i32, start: u64, dur: u64, now: u64, e: Ease) -> i32;
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Spring { pub pos: i64, pub vel: i64, pub target: i64, pub stiffness: i64, pub damping: i64 }
impl Spring { pub fn step(&mut self, dt_ms: u32); pub fn settled(&self) -> bool; }
```
- `ease` with u64 maths and floor division, `u = 1000 - t`: Linear `t`; InQuad `t*t/1000`; OutQuad
  `1000 - u*u/1000`; InOutQuad `t < 500 ? 2*t*t/1000 : 1000 - 2*u*u/1000`; OutCubic
  `1000 - u*u*u/1_000_000`.
- `tween`: `now <= start` gives `from`; `dur == 0` or `now >= start + dur` gives `to`; else
  `t = (now - start) * 1000 / dur` and the result is `from + (to - from) * ease(e, t) / 1000` in i64
  (Rust `/`, toward zero).
- `Spring::step` (i64, saturating): `f = stiffness * (target - pos) / 1000 - damping * vel / 1000`;
  `vel += f * dt / 1000`; `pos += vel * dt / 1000`. `settled`: `|target - pos| <= 1 && |vel| <= 1`.

## indium::widgets (exact)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Nav { Up, Down, PageUp, PageDown, Home, End }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ListState { pub len: usize, pub selected: Option<usize>, pub offset: usize, pub visible: usize }
impl ListState { pub fn new(len: usize, visible: usize) -> ListState; pub fn nav(&mut self, n: Nav) -> bool;
    pub fn click_row(&mut self, row: usize) -> bool; pub fn set_len(&mut self, len: usize) -> bool; }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ScrollState { pub content: u32, pub view: u32, pub pos: u32 }
impl ScrollState { pub fn max(&self) -> u32; pub fn scroll_by(&mut self, d: i32) -> bool; pub fn thumb(&self, track: u32) -> (u32, u32); }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct TabsState { pub count: usize, pub active: usize }
impl TabsState { pub fn next(&mut self) -> bool; pub fn prev(&mut self) -> bool; pub fn select(&mut self, i: usize) -> bool; }
#[derive(Debug, Clone, PartialEq, Eq)] pub struct MenuItem { pub label: String, pub enabled: bool }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct MenuState { pub items: Vec<MenuItem>, pub open: bool, pub hover: Option<usize> }
impl MenuState { pub fn open(&mut self); pub fn close(&mut self); pub fn key(&mut self, k: Nav) -> bool; pub fn enter(&mut self) -> Option<usize>; }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FieldState { pub text: String, pub cursor: usize, pub anchor: Option<usize> } // char indices
impl FieldState { pub fn new(text: &str) -> FieldState; pub fn insert(&mut self, c: char); pub fn backspace(&mut self);
    pub fn delete(&mut self); pub fn left(&mut self, shift: bool); pub fn right(&mut self, shift: bool);
    pub fn home(&mut self, shift: bool); pub fn end(&mut self, shift: bool); pub fn select_all(&mut self);
    pub fn selection(&self) -> Option<(usize, usize)>; pub fn selected_text(&self) -> String; }
```
- Every `-> bool` method returns whether the state changed.
- **List.** `new`: selected None, offset 0. `nav` with `len == 0`: no change. With selected None:
  End selects `len - 1`, every other key selects 0. Otherwise (v = max(visible, 1)): Up
  `s - 1` (saturating), Down `min(s + 1, len - 1)`, PageUp `s - v` (saturating), PageDown
  `min(s + v, len - 1)`, Home 0, End `len - 1`. After any change of selection, offset moves the
  least so that `offset <= s < offset + v`. `click_row(r)`: if `offset + r < len` select it (no
  offset change). `set_len`: selection clamps to `len - 1` (None when 0), offset to
  `min(offset, len.saturating_sub(v))`, then the visibility rule if something is selected.
- **Scroll.** `max = content - view` saturating; `scroll_by` clamps `pos + d` to `0..=max`;
  `thumb(track)`: `content <= view` gives `(0, track)`; else `len = min(track, max(8, track *
  view / content))`, `start = (track - len) * pos / max` (u64 maths).
- **Tabs.** `count == 0`: nothing changes. `next`/`prev` wrap around; `select(i)` only if `i < count`.
- **Menu.** `open` sets open and hover to the first enabled item (None if none); `close` clears
  both. `key` only while open: Down/Up move hover to the next/previous enabled item with wrap
  (from None: first/last enabled), Home/End first/last enabled, PageUp/PageDown like Home/End.
  `enter`: while open with an enabled hover, returns it and closes; else None.
- **Field.** Selection is `(min, max)` of anchor and cursor when anchor is Some and differs from
  cursor. `insert` replaces the selection (or inserts at cursor) and moves the cursor after the
  char. `backspace`/`delete` remove the selection, else the char before/after the cursor. Moves
  without shift: with a selection, `left` goes to its start and `right` to its end; without one,
  `left`/`right` step one char (clamped); `home` goes to 0 and `end` to the char count either way. Every move without shift sets anchor None. With shift: anchor becomes the
  cursor if None, then the cursor moves one char, or to 0 / the end. `select_all`: anchor 0,
  cursor at the end. Any edit sets anchor None.

## Design (fixed by the leader)
- Rust (`src/debug.rs`, host and wasm): one global debug session: `debug_start(src) -> Result<State, String>`
  (compile, start `main`, pause before the first line), `debug_step(mode, breakpoints) -> State`, `debug_stop()`.
  `State { status: paused|done|trapped|error, line, col, output_so_far, frames: [{ name, line }], vars: [{ name,
  value }] }` for the innermost frame (or a chosen frame index). Values printed as Logos source (strings quoted,
  lists as `[1, 2]`, depth-limited to 3, long lists cut with `...`). Wasm exports `athena_debug_start`,
  `athena_debug_step(mode, bp_ptr, bp_len)`, `athena_debug_frame(i)`, `athena_debug_stop`, results as a small text
  format you document (no JSON library needed; one record per line).
- UI: click the gutter to toggle a breakpoint (red dot from `--bad`, stored per file in `athena.breakpoints.v1`);
  activity bar gets a fourth view "Run and Debug" with Variables and Call Stack sections; a floating debug toolbar
  (Continue F5, Step Over F10, Step Into F11, Step Out Shift+F11, Restart Ctrl+Shift+F5, Stop Shift+F5); the
  paused line is highlighted with `--accent` at low opacity plus an arrow in the gutter; program output goes to the
  Output panel as it runs; clicking a frame shows its variables. Palette gets the six debug commands. Editing the
  file while paused stops the session with a status message. Long runs never freeze: step calls are bounded and
  continued from `requestAnimationFrame` on `Budget`.

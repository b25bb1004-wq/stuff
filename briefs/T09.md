# T09 mica: lexer, parser, syntax tree, printer
Worker: haiku, medium. Budget: 170k tokens. First read `briefs/_RULES.md`, then `docs/MICA.md`
(the language reference; it is the specification and you may not change it).

**May touch:** `crates/mica/**` only. `#![forbid(unsafe_code)]` stays.
The crate is `#![cfg_attr(not(test), no_std)]` with `extern crate alloc;`.
Build the front half of the Mica language: text to tokens to a syntax tree. No type checking.

## Public API (exact names; you design the fields of the tree)
```rust
pub struct Span { pub start: u32, pub end: u32 }           // byte offsets; Debug, Clone, Copy, PartialEq, Eq
pub struct Diag { pub span: Span, pub message: alloc::string::String }   // Debug, Clone, PartialEq, Eq
pub fn line_col(src: &str, offset: u32) -> (u32, u32);     // 1-based line and column (in chars)
pub mod lexer {
    pub enum Tok { .. }                                    // one variant per token kind, incl. Newline and Eof
    pub struct Token { pub tok: Tok, pub span: Span }
    pub fn lex(src: &str) -> Result<alloc::vec::Vec<Token>, Diag>;
}
pub mod ast {
    pub struct Module { pub items: Vec<Item> }
    pub enum Item { Type(..), Const(..), Layer(..), Fn(..), Test(..), Prop(..) }
    pub enum Type { .. }  pub enum Stmt { .. }  pub enum Expr { .. }  pub enum Pattern { .. }
    // every node carries its Span; all derive Debug, Clone, PartialEq
}
pub mod parser { pub fn parse(src: &str) -> Result<ast::Module, Diag>; }
pub mod print  { pub fn print(module: &ast::Module) -> alloc::string::String; }   // canonical source text
```
Rules:
- Follow `docs/MICA.md` exactly: the two identifier kinds, the Newline rules (a), (b), (c), the
  precedence table, `x |> f(a)` kept as its own `Pipe` node (do not desugar here), record values
  not allowed bare in the heads of `if`, `while`, `for` and `match`.
- Integer literals that do not fit i64 are lex errors, with one exception handled in the parser:
  unary minus applied to the literal 9223372036854775808 is the minimum int.
- Every error is a `Diag` with a useful span and a message that names what was expected, for
  example: expected ')' to close the call, found newline. The parser stops at the first error.
- Nesting deeper than 200 levels (expressions, blocks, types, patterns) is a `Diag`
  (nesting too deep), never a stack overflow.
- `print` output must parse back to the same tree: for every module `m` that `parse` accepts,
  `print(parse(print(m))) == print(m)`, and the two trees are equal when spans are ignored
  (provide a test helper that compares trees without spans).

## Tests required
- Lexer: every token kind, every escape, number forms and the overflow error, each Newline rule
  with a positive and a negative case, comments, error spans.
- Parser: the full example from `docs/MICA.md`; one directed test per grammar production; the
  precedence of every adjacent pair of levels (such as `1 + 2 * 3`, `a || b && c`,
  `a |> f() |> g()`); at least 25 error cases, each asserting the message and the span.
- A corpus of at least 20 small valid programs in `crates/mica/tests/corpus/*.mica` covering
  every feature, used for the print round-trip test.
- Fuzz (`forall`, at least 2000 cases each): random bytes, random sequences of valid tokens, and
  corpus programs with random single-character edits must return `Ok` or `Err` and never panic.
  Deep nesting (10 000 open parentheses, 10 000 nested blocks) returns a `Diag`.

# T25 titan (crates/titan): Rust kernel that boots on Silicon
Worker: argon-high. Budget: one run, at most 150 minutes. First read `briefs/_RULES.md`, then `docs/TITAN.md`
(the design; follow it), then only the public API of `crates/silicon/src/machine/mod.rs`, `crates/chisel/src/elf.rs`
(`read`, `load`) and `crates/midas/src/lib.rs`.
**May touch:** `crates/titan/` only (the leader already created the crate and added it to the workspace;
replace its `src/lib.rs` header as needed, keep `forbid(unsafe_code)` in lib.rs). No other crate, not the root `Cargo.toml`.
Unsafe is allowed in titan only for MMIO, CSR access, the allocator hookup and page-table writes; each block
gets a `// SAFETY:` comment. Keep host code (`src/lib.rs` modules) safe.

## Layout (exact)
- `src/lib.rs`: `#![cfg_attr(not(test), no_std)]`, host-testable logic, no asm:
  - `pub mod sv39`: `Pte` flags (V R W X U G A D), `PageTable` operations over a `FrameAlloc` trait
    (`map(va, pa, flags)`, `unmap(va)`, `translate(va) -> Option<(pa, flags)>`), Sv39 rules (canonical
    addresses, 3 levels, 4 KiB pages, misaligned or non-canonical input returns `Err`). Unit tests plus a
    `forall` shadow-model test against a `BTreeMap` on a host `Vec<u64>` frame pool.
  - `pub mod trap`: `Cause` enum decoded from `scause` (interrupt flag + code), `Display` names.
  - `pub mod frames`: bitmap frame allocator over a physical range (`alloc`, `free`, double free is `Err`).
- `src/bin/kernel.rs`: `#![cfg_attr(target_os = "none", no_std, no_main)]`; on the host it compiles to an empty
  `fn main() {}` so the normal gate and clippy build it. On `target_os = "none"`: the M-mode shim
  (`global_asm!`), S-mode trap vector, UART console with `core::fmt::Write`, midas as `#[global_allocator]`,
  kernel page table built with `titan::sv39`, `satp` on, then the boot self-test below.
- `build.rs`: when `TARGET` starts with `riscv64`, pass `-T<abs path>/kernel.ld` via `cargo:rustc-link-arg-bins`.

## Boot self-test (UART transcript, exact lines in this order, then finisher `0x5555`)
```
Titan v0.1
ram 0x80000000..0x<end> (<n> MiB)
heap 0x<start>..0x<end>
frames <count> free
sv39 on
heap ok
fault load 0x<addr> scause 13
fault store 0x<addr> scause 15
fault fetch 0x<addr> scause 12
ticks ok
boot ok
```
- `heap ok`: a `Vec` of 10_000 `u64` and a `BTreeMap` of 1_000 entries built, checked and dropped; frames
  free count unchanged after a map, touch, unmap round trip of 64 pages.
- the three faults: load from an unmapped address, store to a read-only page, jump to a page without `X`.
  The trap handler records `scause` and `stval`, skips the faulting instruction (for fetch, return to a
  recovery address), and the test checks `stval` equals the address used.
- `ticks ok`: at least 3 timer ticks observed by the S-mode handler while spinning.
- Any failure prints `FAIL <what>` and writes `(1 << 16) | 0x3333` to the finisher.
- Must work for any `ram_size` from 16 MiB to 256 MiB. The host passes it in `a1`: set `machine.cpu.x[11] = ram_size`
  before `run` (`a0` = hart id 0). The shim keeps `a1` and hands it to `kmain`. Say so in a comment at the top of
  `kernel.rs`.

## Host test (`tests/boot.rs`)
Builds the kernel with `cargo build -p titan --bin kernel --release --target riscv64gc-unknown-none-elf`
into `CARGO_TARGET_DIR=<workspace>/target/titan-kernel` (separate dir: no lock with the outer build), reads
the ELF with `chisel::elf::read`, loads it with `chisel::elf::load` into `silicon::machine::Machine` (16 MiB
and 64 MiB), runs at most 50_000_000 steps, and asserts `Exit::Pass` plus every transcript line above.
`chisel` and `silicon` are dev-dependencies only; `midas` is a normal dependency.

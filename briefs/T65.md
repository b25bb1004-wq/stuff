## HTML tokenizer (WHATWG states: data, RCDATA, RAWTEXT, script data, tag open/name, attributes, comments, DOCTYPE)
- Tag and attribute names lowercased; attribute values quoted `"` / `'`, unquoted, or absent (value
  ""); duplicate attributes: keep the first. `/>` sets `self_closing`.
- Character references in text and attribute values: numeric (`&#65;` `&#x41;` `&#X41;`; 0, above
  0x10FFFF, or a surrogate -> U+FFFD; 0x80-0x9F mapped by the windows-1252 table, e.g. `&#150;` ->
  U+2013) and named, at least: amp lt gt quot apos nbsp copy reg trade hellip mdash ndash lsquo rsquo
  ldquo rdquo laquo raquo deg plusmn times divide middot para sect euro pound yen cent bull larr rarr
  uarr darr hearts. An unknown name stays literal; a lone `&` is literal.
- `script`, `style` are raw text (no references, no tags until the matching end tag);
  `title`, `textarea` are RCDATA (references decoded, no tags).
- Comments `<!-- x -->` -> Comment(" x "); `<!DOCTYPE html>` (any case) -> Doctype("html").
- Input preprocessing: CRLF and CR -> LF.

## Tree construction (subset of WHATWG; anything not listed is an ordinary element)
- Doctype and comments before `<html>` become children of the Document. Implied `html`, `head`,
  `body`; whitespace text before `<head>`/body content is dropped; `title meta link style script
  base` before body content go in `head`; any other start tag or non-whitespace text closes head
  and opens body. Whitespace text between `</head>` and body content is appended to `html`.
  Explicit `<html>`/`<body>` start tags when the element exists add missing attributes only.
  `</body>` and `</html>` keep body as the insertion point (later content still goes into body).
- Void elements (area base br col embed hr img input link meta source track wbr) take no children.
- Start tags address article aside blockquote center details dialog dir div dl fieldset figcaption
  figure footer header hgroup main menu nav ol p section summary ul h1-h6 pre listing form hr table
  li dd dt close an open `p` in button scope first. `h1`-`h6` when the current node is a heading
  pops it. `li` closes an open `li` (walk down the stack: stop at `li`; stop without closing at a
  special element other than address, div, p); `dd`/`dt` likewise for `dd`/`dt`.
- A newline right after `<pre>`, `<listing>`, `<textarea>` is dropped.
- `</p>` with no `p` in button scope inserts an empty `<p>`. Any other end tag: if an element with
  that name is in scope (boundaries: applet caption html table td th marquee object template),
  generate implied end tags (dd dt li optgroup option p rb rp rt rtc) except that name and pop up
  to it; otherwise ignore it. No adoption agency or formatting reconstruction.
- Tables: inside `table`, `tr`/`td`/`th` without `tbody` imply `tbody` (and `td`/`th` imply `tr`);
  `thead tbody tfoot` close an open section; a new `tr` closes an open `tr`, a new `td`/`th` closes
  an open cell; `</table>` closes everything up to the table; non-whitespace text directly in
  `table`/`tbody`/`thead`/`tfoot`/`tr` is inserted just before the table (foster parenting).
  `caption col colgroup tbody td tfoot th thead tr` start tags outside a table are ignored.
- Adjacent text in the same parent merges into one Text node. EOF closes everything.

`Document::dump()` (html5lib tests format): one line per node, `| ` then two spaces per depth
(children of the Document at depth 0): `<!DOCTYPE html>`, `<name>`, `"text"` (raw, no escaping),
`<!-- text -->`; an element's attributes come first as its children, sorted by name, `name="value"`.
Lines end with `\n`.

## CSS (match tinycss2 1.5 exactly)
- Tokenizer per CSS Syntax 3: preprocessing (CRLF/CR/FF -> LF, NUL -> U+FFFD), escapes (bad code
  points -> U+FFFD), ident/function/url/bad-url (`url(` with an unquoted value), strings and
  bad strings (newline ends a bad string; EOF ends a good one), hash `id` flag = would start an
  ident, numbers: `int` = no `.` and no exponent; compute `value` by parsing the number's text with
  `str::parse::<f64>()` (so `-0` is -0.0 and `1e400` is inf), CDO/CDC, comments dropped.
- `parse_values` nests `()` `[]` `{}` blocks and functions; EOF closes them.
- Declarations (per entry): skip whitespace and `;`; an at-rule (prelude up to `;` or a `{}` block)
  is consumed and dropped; otherwise collect values up to the next top-level `;`. Valid only if it is
  ident, optional whitespace, `:`, value. Then walk the value with a state machine, ignoring
  whitespace: state starts `value`; a `!` in state `value` -> `bang` (does not count as a value); an
  ident "important" (any case) in state `bang` -> `important` (does not count); any other token ->
  state `value` and counts as a value, and a `{}` block that comes after an earlier counted value
  makes the declaration invalid (`a: {x} y` valid, `a: x {y}` and `a: {x} {y}` invalid, no exception
  for `--` names). Ending in state `important` sets `important` and removes everything from that `!`
  on (`x!!important` and `x ! ! important` are not important). Value trimmed of whitespace at both
  ends; name kept as written. Invalid entries are dropped.
- Stylesheet: skip whitespace, CDO, CDC at the top level. At-rule: prelude up to `;` (no block)
  or a `{}` block (raw values) or EOF (no block). Otherwise a style rule: prelude up to a `{}`
  block, whose contents are parsed as declarations (nested at-rules dropped); a prelude ended by
  EOF is dropped.

## Selectors (Level 4 subset, HTML document, no quirks)
Type (case-insensitive) and `*`, `.class` (whitespace-separated list), `#id`, attributes `[a]`
`[a=v]` `[a~=v]` `[a|=v]` `[a^=v]` `[a$=v]` `[a*=v]` (v an ident or a string; `[a^=""]` etc. never
match), pseudo-classes (case-insensitive) `:root :first-child :last-child :only-child
:first-of-type :last-of-type :empty` (no element children and no non-whitespace text) and
`:nth-child(An+B)` `:nth-last-child()` `:nth-of-type()` `:nth-last-of-type()` (full An+B syntax incl.
`odd`, `even`, `-n+3`, spaces around the sign), `:not(compound)`; combinators descendant, `>`,
`+`, `~`. Anything else (pseudo-elements, unknown pseudo-classes, `#1a`, `[a=3]`, dangling
combinators, empty list items, `:not()`) is a `SelectorError`. The root element counts as the only
child of the Document, so it matches `:first-child`, `:last-child`, `:only-child`, `:nth-child(1)` etc.
Whitespace around `,` and inside `:nth-*( odd )` is allowed. Specificity per Selectors 4.

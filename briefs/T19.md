# T19 logos: reference interpreter for the typed IR
Worker: hydrogen (or haiku). First read `briefs/_RULES.md`, then `docs/LOGOS.md` section Semantics,
then `crates/logos/src/ir.rs` (from T10; do not change it).
This interpreter is the oracle: Cobalt's Elysium output (T18) and RV64 output (T29, T30) must
print the same thing for the same program. Keep it simple and obviously right, not fast.

**May touch:** `crates/logos/src/eval.rs` (split if over about 400 lines), `src/lib.rs` for the
module line, tests beside it.

## Public API (exact)
```rust
pub mod eval {
    #[derive(Debug, Clone, PartialEq)]
    pub enum Trap { Overflow, DivideByZero, IndexOutOfRange, AssertFailed(String), OutOfFuel,
                    StackOverflow, NoExtern(String) }
    #[derive(Debug, Clone, PartialEq)]
    pub struct Outcome { pub output: String, pub result: Result<(), (Trap, Span)> }
    pub fn run_main(p: &ir::Program, input: &str, fuel: u64) -> Outcome;      // externs below
    pub fn run_test(p: &ir::Program, index: usize, fuel: u64) -> Outcome;
    pub fn run_prop(p: &ir::Program, index: usize, seed: u64, cases: u32, fuel: u64) -> Outcome;
}
```
## Behaviour
- Every trap rule of `docs/LOGOS.md` Semantics, with the span of the instruction that trapped.
- Externs: `io.print` appends to `output` (no newline added), `io.read_line` reads lines from
  `input` (`none` at the end), `time.now` returns 0, `rand.next` a fixed sequence from the seed 1;
  any other extern is `NoExtern(name)`.
- Fuel: one unit per IR instruction; `OutOfFuel` at the limit. Call depth over 10 000 is
  `StackOverflow`. The loop is iterative (own frame stack).
- Props: draw arguments with `assay`-style seeded generation inside this module (private copy, no
  dev-dependency in library code): ints in -1000..=1000 half the time and any i64 otherwise,
  bytes, bools, short strings, short arrays; skip cases where the guard is false; stop at the
  first failure and say the case in `output`.

## Tests required
Every `tests/typed/*.logos` program runs; hand-checked outputs for at least 15 programs
(factorial, string building, match on variants, records shared and mutated, options, slices,
pipes); one test per trap kind; prop failure is found and replayed with the same seed.

## Extra check the leader will run
Its own programs with outputs computed by hand, and every trap kind.

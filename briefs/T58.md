## Public API (exact)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Rgba(pub u8, pub u8, pub u8, pub u8);          // straight (not premultiplied) alpha
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Canvas { pub width: u32, pub height: u32, pub pixels: Vec<Rgba> } // row major
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Rect { pub x: i32, pub y: i32, pub w: u32, pub h: u32 }
impl Canvas {
    pub fn new(width: u32, height: u32, fill: Rgba) -> Canvas;
    pub fn get(&self, x: i32, y: i32) -> Option<Rgba>;
    pub fn blend(&mut self, x: i32, y: i32, c: Rgba);      // source-over; off-canvas ignored
    pub fn fill_rect(&mut self, r: Rect, c: Rgba);          // clipped, blended
    pub fn stroke_rect(&mut self, r: Rect, c: Rgba);        // 1-pixel border inside r
    pub fn line(&mut self, x0: i32, y0: i32, x1: i32, y1: i32, c: Rgba); // Bresenham, both ends drawn
    pub fn fill_polygon(&mut self, pts: &[(f32, f32)], c: Rgba);         // non-zero winding, AA coverage
    pub fn draw(&mut self, src: &Canvas, x: i32, y: i32);   // source-over copy, clipped
    pub fn to_ppm(&self) -> Vec<u8>;                         // P6, alpha dropped (for eyeballing)
}
pub fn over(dst: Rgba, src: Rgba) -> Rgba;
```
## Behaviour
- `over`: integer source-over with straight alpha, exact rules: `sa = src.3`, `da = dst.3`;
  `oa = sa + (da*(255-sa) + 127) / 255` (u32 integer division); for each channel `oc = (src*sa*255 + dst*da*(255-sa) + oa*255/2) / (oa*255)`
  when `oa > 0`, else 0. `over(d, Rgba(r,g,b,255)) == Rgba(r,g,b,255)`; `over(d, Rgba(_,_,_,0)) == d`.
- `line`: classic integer Bresenham for all octants; the pixel set from (x0,y0) to (x1,y1) equals
  the set from (x1,y1) to (x0,y0); each pixel blended exactly once.
- `fill_polygon`: pixel coverage = area of the pixel square inside the polygon (non-zero rule),
  computed analytically per scanline (signed-area accumulation as in font rasterisers) or by 16x16
  supersampling, your choice, but documented; coverage scales the source alpha
  (`a = round(c.3 * coverage)`), each pixel blended once. Fully covered pixels get exactly `c`'s
  alpha. Self-intersecting and multi-contour shapes are not needed beyond one closed path.
- Every function is total: huge or negative coordinates, empty rects, polygons with fewer than 3
  points, NaN points (skip) never panic and never allocate in proportion to coordinates.

## Tests required
- `over` table of at least 20 cases worked out by hand, plus a `forall` check (2000 cases) that
  opaque source wins, transparent source keeps dst, and result alpha is monotone in `sa`.
- Line: all 8 octants and the 4 axis cases on a 9x9 canvas against hand-drawn ASCII goldens
  (`#` set, `.` unset) in the test file; symmetry under swapping ends (`forall`, 500 cases).
- Rect clipping at every edge and fully outside; `stroke_rect` for w or h of 1 and 2.
- Polygon: an axis-aligned square on integer corners equals `fill_rect` exactly; a square offset
  by 0.5 gives 0.5 coverage edges and 0.25 corners (alpha within 1); a triangle's summed coverage
  equals its area within 1 %; a polygon wound either way gives the same pixels.
- Fuzz (`forall`, 1000 cases): random coordinates in ±1e6 and NaN never panic.

## Design
- `Buddy`: binary buddy allocator over one caller-supplied memory region. Minimum block 4096
  bytes (`PAGE`), orders 0..=MAX_ORDER, free lists threaded through the free blocks themselves
  (intrusive), a bitmap or order table stored at the start of the region. Splits on allocate,
  merges with its buddy on free.
- `Heap`: size classes 16, 32, 64, ... 2048 bytes. Each class takes pages from the `Buddy` and
  carves them into slots with an intrusive free list. Requests above 2048 bytes (or with
  alignment above the class size) go straight to the `Buddy`.
- `Locked<T>`: a spin lock (`core::sync::atomic::AtomicBool`) so `Locked<Heap>` can implement
  `core::alloc::GlobalAlloc`.

## Public API (exact)
```rust
pub const PAGE: usize = 4096;
pub struct Buddy;
impl Buddy {
    /// # Safety: `base..base+len` must be valid, writable, unused memory for the Buddy's life.
    pub unsafe fn new(base: *mut u8, len: usize) -> Option<Buddy>;   // None if too small
    pub fn alloc_pages(&mut self, order: u32) -> Option<core::ptr::NonNull<u8>>; // 2^order pages, page aligned
    /// # Safety: `ptr` came from `alloc_pages(order)` on this Buddy and is not freed yet.
    pub unsafe fn free_pages(&mut self, ptr: core::ptr::NonNull<u8>, order: u32);
    pub fn free_bytes(&self) -> usize;
    pub fn total_bytes(&self) -> usize;   // usable bytes after metadata
}
pub struct Heap;
impl Heap {
    pub unsafe fn new(base: *mut u8, len: usize) -> Option<Heap>;
    pub fn alloc(&mut self, layout: core::alloc::Layout) -> *mut u8;      // null on failure
    pub unsafe fn dealloc(&mut self, ptr: *mut u8, layout: core::alloc::Layout);
    pub fn used_bytes(&self) -> usize;    // bytes handed to callers, rounded to class or pages
    pub fn check(&self) -> bool;          // walk every free list; false if any invariant is broken
}
pub struct Locked<T>;                     // new(T), lock() -> guard
unsafe impl core::alloc::GlobalAlloc for Locked<Heap> { .. }   // alloc, dealloc (default realloc is fine)
```
Zero-size layouts return a dangling aligned non-null pointer and are ignored on dealloc.

## Tests required (tests may use `std`; back the arena with a leaked `Vec<u8>` or `Box<[u8]>`)
- Buddy: allocate every order, free in random order, then one max-order block must succeed
  again (full merge); `free_bytes` returns to its start value; exhaustion returns `None`.
- Heap property test (`forall`, at least 200 cases, about 2000 operations each): random
  alloc/dealloc with random sizes 1..=20000 and alignments 1..=4096 against a shadow list.
  Check: pointer alignment; no two live blocks overlap; each block is filled with a tag byte on
  alloc and still holds it at dealloc; `check()` is true every 100 operations; after freeing
  everything `used_bytes() == 0` and a max-size allocation succeeds.
- Out-of-memory returns null, never panics, and the heap still works afterwards.
- `Locked<Heap>` through the `GlobalAlloc` trait from 4 threads, 5000 operations each, same
  tag-byte check.

## Tool
- `elysium`: `verify FILE.mbc`, `dis FILE.mbc` (one instruction per line with offsets), `run FILE.mbc
  [--fuel N]` (result and steps). Tests build a small module with the library's own encoder.

## Tests
`tests/cli.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input each
(exit 1 and a `elysium:` message), an unknown subcommand (exit 2).

## Report

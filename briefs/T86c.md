## Tool
- `silicon`: `run ELF [--steps N] [--ram MiB] [--trace]`: chisel depends on silicon, so this bin lives in `crates/chisel/src/bin/silicon.rs`
  (with `crates/chisel/tests/cli_silicon.rs`) and loads with `chisel::elf::{read, load}`; run, UART output to stdout, then
  `exit: <Exit>` and `instret: N`; `--trace` prints `pc inst` lines up to 1000. Test with an ELF built in the test
  by `chisel::assemble` (dev-dep) that prints `hi` and exits.

## Tests
`tests/cli_silicon.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input each
(exit 1 and a `silicon:` message), an unknown subcommand (exit 2).

## Public API (exact)
```rust
// tectonic::audio
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Sound { pub rate: u32, pub samples: Vec<i16> }          // mono PCM
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct VoiceId(pub u64);                                        // never reused, from 0
pub fn tone(rate: u32, freq_hz: u32, ms: u32, amp: i16) -> Sound;   // square wave
pub fn wav(rate: u32, stereo: &[i16]) -> Vec<u8>;                   // 16-bit PCM, 2 channels
#[derive(Debug, Clone)]
pub struct Mixer { /* private */ }
impl Mixer {
    pub fn new(rate: u32) -> Mixer;
    pub fn play(&mut self, s: &Sound, volume: Fx, pan: Fx, looped: bool) -> VoiceId;
    pub fn stop(&mut self, v: VoiceId) -> bool;                     // false if not playing
    pub fn set_volume(&mut self, v: VoiceId, volume: Fx) -> bool;
    pub fn playing(&self) -> usize;
    pub fn mix(&mut self, out: &mut [i16]);                         // interleaved L,R; odd len: last slot 0
}
// tectonic::scene
pub enum Command { Push(Box<dyn Scene>), Pop, Replace(Box<dyn Scene>), Quit }
pub trait Scene {
    fn update(&mut self, keys: u32, out: &mut Vec<Command>);
    fn state_hash(&self) -> u64;
}
pub struct Stage { /* private */ }
impl Stage {
    pub fn new(root: Box<dyn Scene>) -> Stage;
    pub fn step(&mut self, keys: u32) -> bool;   // false once quit or the stack is empty
    pub fn depth(&self) -> usize;
    pub fn frame(&self) -> u64;                  // completed steps that ran a scene
    pub fn hash(&self) -> u64;
}
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Input { pub frame: u64, pub keys: u32 }
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Recorder { pub inputs: Vec<Input> }
impl Recorder {
    pub fn new() -> Recorder;
    pub fn record(&mut self, frame: u64, keys: u32);   // stores only changes of keys
    pub fn keys_at(&self, frame: u64) -> u32;
    pub fn encode(&self) -> Vec<u8>;
    pub fn decode(bytes: &[u8]) -> Option<Recorder>;
}
pub fn replay(stage: &mut Stage, rec: &Recorder, frames: u64) -> u64;  // returns stage.hash()
```

## Audio rules (exact; the leader models them bit for bit)
- `tone`: `n = rate * ms / 1000` samples (u64 maths); sample `i` is `amp` if
  `(i * freq_hz * 2 / rate) % 2 == 0`, else `-amp` (u64 maths; `freq_hz == 0` or `rate == 0`
  gives all `amp`, or no samples when `rate == 0`).
- `play` clamps `volume` to `0..=ONE` and `pan` to `-ONE..=ONE`. Gains: `gl = vol * (ONE - pan) / 2`,
  `gr = vol * (ONE + pan) / 2`, computed as raw `(vol.0 * (65536 - pan.0)) >> 17` (likewise for
  right). `set_volume` clamps and recomputes both gains with the voice's pan. An empty sound or a
  sound with rate 0 gives an id but is never playing.
- Each voice keeps a 32.32 position starting at 0 and `step = (sound.rate << 32) / mixer.rate`
  (u64; mixer rate 0 means `mix` writes zeros). For each output frame, every playing voice in
  ascending id order contributes `(s as i64 * g) >> 16` to each side, where `s = samples[pos >> 32]`
  and `g` is that side's raw gain; then `pos += step`. If `pos >> 32 >= len`: a looped voice
  sets `pos -= len << 32` (repeat while still past the end), others stop. Sums are i64 and
  saturate to i16 when written.
- `wav`: the standard 44-byte RIFF header (`RIFF`, size, `WAVE`, `fmt ` chunk of 16 bytes, PCM 1,
  2 channels, rate, byte rate `rate*4`, block align 4, 16 bits, `data`, size), then samples LE.

## Scene rules (exact)
- `step(keys)`: if quit or empty, return false. Otherwise call `update` on the top scene only,
  `frame += 1`, then apply its commands in order: Push puts a scene on top, Pop removes the top,
  Replace swaps the top (or pushes if empty), Quit stops the stage (later commands are ignored).
  Return `!quit && depth > 0`.
- `hash()`: FNV-1a 64 over `frame` LE, `depth` as u64 LE, then each scene's `state_hash()` LE from
  bottom to top, then one byte 1 if quit else 0.
- `record(frame, keys)`: append `Input` only when keys differ from `keys_at(frame)`; frames must be
  recorded in non-decreasing order, an earlier frame is ignored, an equal frame overwrites the last.
  `keys_at(f)` is the keys of the last input with `frame <= f`, else 0.
- `encode`: b"TREC", u32 LE count, then per input u64 LE frame, u32 LE keys. `decode` returns None
  for any malformed input (bad magic, wrong length, frames decreasing) and never panics.
- `replay(stage, rec, frames)`: for frame `f` in `0..frames` while `step` returns true, call
  `stage.step(rec.keys_at(stage.frame()))`; return `stage.hash()`.

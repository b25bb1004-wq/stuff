## Public API (exact)
```rust
// tectonic::phys
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Shape { Circle { r: Fx }, Aabb { half: Vec2 } }          // no rotation
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Body { pub pos: Vec2, pub vel: Vec2, pub inv_mass: Fx, pub restitution: Fx, pub shape: Shape }
pub type BodyId = usize;
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Contact { pub a: BodyId, pub b: BodyId, pub normal: Vec2, pub depth: Fx }
pub fn collide(a: &Body, b: &Body) -> Option<(Vec2, Fx)>; // unit normal from a to b, depth > 0
#[derive(Debug, Clone)]
pub struct World { pub gravity: Vec2 }
impl World {
    pub fn new(gravity: Vec2) -> World;
    pub fn add(&mut self, b: Body) -> BodyId;          // ids are never reused
    pub fn remove(&mut self, id: BodyId) -> bool;
    pub fn body(&self, id: BodyId) -> Option<&Body>;
    pub fn body_mut(&mut self, id: BodyId) -> Option<&mut Body>;
    pub fn ids(&self) -> Vec<BodyId>;                  // live ids, ascending
    pub fn step(&mut self, dt: Fx);
    pub fn contacts(&self) -> &[Contact];              // contacts found in the last step
    pub fn kinetic_energy(&self) -> Fx;                // sum of v.v / (2 inv_mass) over dynamic bodies
}
// tectonic::draw
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Camera { pub center: Vec2, pub scale: Fx }  // pixels per world unit
pub fn to_screen(cam: &Camera, width: u32, height: u32, p: Vec2) -> (i32, i32);
pub fn draw_world(canvas: &mut Canvas, cam: &Camera, world: &World, color: &dyn Fn(BodyId) -> Rgba);
```

## Physics rules
- `inv_mass == 0` is a static body: never moves, ignores gravity, infinite mass. Two static bodies
  never collide. Restitution of a pair is the smaller of the two (clamped to 0..=1).
- `collide`: circle-circle, circle-AABB (closest point; a circle centre inside the box pushes out
  along the axis of least penetration), AABB-AABB (axis of least penetration; ties pick x).
  Touching without overlap (depth 0) is no contact. Coincident circle centres use normal (1, 0).
- `step(dt)`: every dynamic body `vel += gravity * dt`. Then split the step into `n` equal
  substeps, `n` = the smallest count such that no dynamic body moves more than half of its
  smallest extent (circle radius, smaller half-size of a box) in one substep, at least 1, at most
  64. Each substep: `pos += vel * sdt`; find all overlapping pairs (pairs in ascending id order,
  lower id is `a`); for each, if the bodies approach along the normal, apply the impulse
  `j = -(1 + e) * (vrel . n) / (inv_a + inv_b)`; then positional correction
  `0.8 * max(depth - slop, 0) / (inv_a + inv_b)` split by inverse mass, with `slop = Fx::from_ratio(1, 100)`.
  `contacts()` keeps the pairs of the last substep.
- Guarantees the leader will test: no tunnelling while every `|v| * dt <= 32 * smallest extent`;
  momentum conserved in collisions between dynamic bodies with no statics or gravity (up to
  rounding of 1 raw unit per collision per body); with `e <= 1` and no gravity, kinetic energy
  never rises above its start by more than 1%; a stack of 5 boxes on a static floor under gravity
  settles and stays sunk less than `2 * slop`; identical worlds stepped identically are equal.
- Nothing panics: saturating `Fx` arithmetic, zero-length vectors handled.

## Renderer rules
- `to_screen`: `sx = width / 2 + round((p.x - c.x) * scale)`, `sy = height / 2 - round((p.y - c.y) * scale)`
  (world y up, screen y down; integer division floors, `round` is `Fx::round`).
- `draw_world` fills each body in its colour: circles as filled discs, boxes as filled
  rectangles, using pigment. Bodies paint in ascending id order. The pixel at a body's screen
  centre gets its colour when the body is at least 2 pixels across; pixels more than 1 pixel
  outside every body are untouched.

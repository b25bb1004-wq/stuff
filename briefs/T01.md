## Public API (exact)
```rust
pub enum Error { BadTag, BadLength }            // derive Debug, Clone, Copy, PartialEq, Eq

pub mod sha256 { pub struct Sha256; // new(), update(&mut self, &[u8]), finalize(self) -> [u8; 32]
                 pub fn digest(data: &[u8]) -> [u8; 32]; }
pub mod sha512 { pub struct Sha512; // new(), update, finalize(self) -> [u8; 64]
                 pub fn digest(data: &[u8]) -> [u8; 64]; }
pub mod hmac   { pub fn hmac_sha256(key: &[u8], msg: &[u8]) -> [u8; 32]; }
pub mod hkdf   { pub fn extract(salt: &[u8], ikm: &[u8]) -> [u8; 32];
                 pub fn expand(prk: &[u8; 32], info: &[u8], out: &mut [u8]) -> Result<(), Error>; } // BadLength if out > 255*32
pub mod chacha20 { pub fn xor(key: &[u8; 32], nonce: &[u8; 12], counter: u32, data: &mut [u8]); } // RFC 8439
pub mod poly1305 { pub fn mac(key: &[u8; 32], msg: &[u8]) -> [u8; 16]; }
pub mod aead   { pub fn seal(key: &[u8; 32], nonce: &[u8; 12], aad: &[u8], plaintext: &[u8]) -> Vec<u8>; // ciphertext || 16-byte tag
                 pub fn open(key: &[u8; 32], nonce: &[u8; 12], aad: &[u8], sealed: &[u8]) -> Result<Vec<u8>, Error>; }
pub mod ct     { pub fn eq(a: &[u8], b: &[u8]) -> bool; } // constant time for equal lengths
```
`aead::open` compares the tag with `ct::eq` before decrypting and returns `BadTag` on mismatch,
`BadLength` if `sealed` is shorter than 16 bytes. Poly1305 must not branch on secret data.

## Tests required
- SHA-256 and SHA-512: empty string, "abc", the 448-bit and 896-bit NIST messages, and one
  million `a` bytes.
- HMAC-SHA-256: RFC 4231 cases 1, 2, 3, 6. HKDF: RFC 5869 test cases 1 and 3.
- RFC 8439: ChaCha20 block and encryption (sections 2.3.2, 2.4.2), Poly1305 (2.5.2), AEAD
  (2.8.2), including decrypting the RFC ciphertext.
- Properties with `forall`: incremental hashing at random split points equals one-shot;
  `open(seal(x)) == x` for random key, nonce, aad, message (lengths 0 to 300); flipping any one
  bit of the sealed output or of the aad gives `Err(BadTag)`; `chacha20::xor` twice is identity.

# T79a fuzz soak (crates/mercury and other idle crates): every parser and decoder, new seeds
Worker: hydrogen (agy). Budget: one run, at most 120 minutes. First read `briefs/_RULES.md`.
Crates in scope (others are busy; do not touch them): `crates/mercury`, `crates/chisel`,
`crates/elysium`, `crates/chronos`, `crates/argo`, `crates/krypton`, `crates/hades`,
`crates/xenon`, `crates/logos`, `crates/pigment`, `crates/silicon`.
**May touch:** one new `tests/soak.rs` in each crate in scope; `src/` of a crate in scope only to fix
a panic, hang or out-of-memory the soak found (smallest fix, plus a regression test in soak.rs).

## What each soak.rs does (exact)
- Uses `assay::Rng` only (add `assay` as a dev-dependency where missing), seeds from
  `STRATA_SOAK_SEED` (default `0x5EED_79A`), and runs for `STRATA_SOAK_MS` milliseconds per target
  (default 300, so the normal gate stays fast). Prints the seed and case count per target.
- Targets: every public function that takes bytes or text from outside: request and response
  parsers, WebSocket frames (mercury); assembler and ELF loader (chisel); module decode and
  verify, then running verified modules with small fuel (elysium); pack, tree and object decoders,
  diff and merge on random text (chronos); manifest, version and requirement parsers, package
  decode (argo); shell parse and expand (krypton); fsck and mount on random and mutated disks
  (hades); wire decoders and the connection fed random datagrams (xenon); lexer, parser and
  checker on random and mutated source (logos); PNG decode and inflate (pigment); the CPU on random
  instruction words for a bounded step count (silicon).
- Inputs: half purely random bytes, half mutations (bit flips, truncation, splices, repeated
  chunks) of valid inputs the crate itself produces. Every call must return without panicking,
  within 1 second per case, and allocate at most 64 MiB (check sizes you pass, do not measure).

## Report
`reports/T79a.md`: per crate, targets, cases run at the default budget and with
`STRATA_SOAK_MS=60000`, and every defect found with its fix (file:line) or `none found`.

## Extra check the leader will run
Each soak.rs run with a fresh seed and a longer budget; every fix re-read; `cargo test` of every
crate in scope; the workspace gate.

## Build
- Exactly the public API in C3, `#![no_std]` with `extern crate alloc;`, and `extern crate std;` only when
  `not(target_os = "none")`.
- `src/host/`: every function on std (`std::fs`, `std::io`, `std::env::args`, `std::process`,
  `std::time::Instant` started at first use for `uptime_ms`). Map `std::io::ErrorKind` to `Error`.
  `proc::result(env)` prints `env` plus a newline to stdout. `child_result` returns `Ok(None)`.
- `src/titan/`: `ecall` wrappers for calls 0 to 15, 16 (`result`) and 25 (`child_result`, buffer 64 KiB)
  with the numbers in C2 and docs/TITAN.md; negative results map to `Error` (-1 BadArg, -2 NotFound,
  -3 NoMem, -4 BadFd, -5 Exists, -6 NotDir, -7 Busy). Files: `open` flags per docs/TITAN.md; `read_dir`
  parses what `readdir` returns (read `userland` code to learn its format); `is_dir` and `exists` may be
  built from `open` and `readdir`. `read_stdin` reads fd 0 until a read returns 0.
- `main!` macro: host form is `fn main() { std::process::exit($f()) }`; titan form defines `_start`
  (argc in a0, argv in a1), a global allocator, a panic handler (message to stderr, exit 101), and calls
  `exit($f())`.

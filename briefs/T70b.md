## Script contract (exact)
- The script defines `fn update() -> Unit`; optional `fn init() -> Unit` runs once before the first
  `update`. Host externs (names exact): `game.keys() -> Int` (this frame's keys), `game.frame() ->
  Int` (frames run before this one), `game.get(i: Int) -> Int` and `game.set(i: Int, v: Int) ->
  Unit` (256 Int slots, all 0 at start; out of range reads 0, writes ignored), `game.rand(n: Int)
  -> Int` (`helios::rng` seeded with `seed`, uniform in `0..n`, 0 when `n <= 0`),
  `game.rect(x: Int, y: Int, w: Int, h: Int, color: Int) -> Unit` (appended to this frame's draws;
  values saturate to i32 / u32 range), `game.log(s: String) -> Unit`, `game.quit() -> Unit`
  (issue `Command::Quit` after this frame).
- Each `update` call starts a fresh draw list and runs with `fuel_per_frame` fuel. A trap or
  out-of-fuel appends `trap: <kind>\n` to the log and issues `Command::Pop`; the frame's draws are kept.
- `state_hash` = FNV-1a 64 over the 256 slots (i64 LE) then every draw (x, y, w, h as i32 LE, color
  as u32 LE). Same seed and same inputs give the same hashes.

## The game

2 up, 3 down, 4 action), score in slot 0, lives in slot 1, game over sets slot 2 to 1 and calls

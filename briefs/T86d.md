**May touch:** `crates/hades/src/bin/hades.rs`, `crates/hades/tests/cli.rs`, `crates/hades/Cargo.toml` (a `[[bin]]` entry if needed) only. Do not change library code; if a subcommand needs something the library does not

## Tool
- `hades`: `mkfs IMG [--blocks N]`, `ls IMG PATH`, `cat IMG PATH`, `put IMG SRC PATH`, `rm IMG PATH`,
  `mkdir IMG PATH`, `fsck IMG` (prints errors, exit 1 if any). The image is a plain file used through `MemDisk`
  (read whole, write back atomically: temp file then rename).

## Tests
`tests/cli.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input each
(exit 1 and a `hades:` message), an unknown subcommand (exit 2).

## Report
`reports/T86d.md` (at most 10 lines): subcommands, anything left out and why, tests, gate last line.

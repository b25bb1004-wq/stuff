## Public API (exact, re-exported from the crate root)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FlateError { Truncated, Invalid, Checksum, TooLarge }
/// Raw DEFLATE (RFC 1951). Output longer than `max_out` -> Err(TooLarge) (bomb guard).
pub fn inflate(data: &[u8], max_out: usize) -> Result<alloc::vec::Vec<u8>, FlateError>;
/// Raw DEFLATE. level 0 = stored blocks only; 1..=9 = LZ77 (32 KiB window, lazy matching at
/// 4 and above) with dynamic Huffman blocks (fixed or stored when smaller). Levels above 9 act as 9.
pub fn deflate(data: &[u8], level: u8) -> alloc::vec::Vec<u8>;
/// zlib wrapper (RFC 1950): header check, no preset dictionary, Adler-32 trailer checked.
pub fn zlib_decompress(data: &[u8], max_out: usize) -> Result<alloc::vec::Vec<u8>, FlateError>;
pub fn zlib_compress(data: &[u8], level: u8) -> alloc::vec::Vec<u8>;
pub fn crc32(data: &[u8]) -> u32;   // IEEE, as in PNG and zlib.crc32
pub fn adler32(data: &[u8]) -> u32;
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PngError { Signature, Chunk, Crc, Header, Unsupported, Data, TooLarge }
/// Any valid PNG -> straight-alpha RGBA8 canvas. `max_pixels` bounds width*height.
pub fn decode_png(data: &[u8], max_pixels: u64) -> Result<Canvas, PngError>;
/// RGBA8, colour type 6, bit depth 8, no interlace; per row the filter (0-4) with the smallest
/// sum of absolute signed bytes; IDAT via zlib_compress level 6; chunks IHDR, IDAT, IEND.
pub fn encode_png(c: &Canvas) -> alloc::vec::Vec<u8>;
```
## Behaviour
- `inflate`: stored, fixed and dynamic blocks; distances up to 32768; rejects bad code lengths,
  over-subscribed or incomplete code sets (except the single-code distance case RFC allows),
  distances before the start of output, stored LEN/NLEN mismatch. Trailing bytes after the final
  block are ignored. Never panics, never allocates more than about `max_out` plus 64 KiB.
- `deflate` output must inflate (by zlib itself) to the input; at level 6 on text it must be no
  more than 10% larger than zlib level 6. Deterministic.
- PNG decode: colour types 0, 2, 3, 4, 6; bit depths 1, 2, 4, 8, 16 as the spec allows per
  type (16-bit: keep the high byte); PLTE; tRNS for types 0, 2 and 3; Adam7 interlace; all five
  filters; multiple IDAT chunks; CRC checked on every chunk; unknown ancillary chunks skipped,
  unknown critical chunks -> Unsupported; gamma and colour chunks ignored.

## Tests required
- Known vectors: `crc32(b"123456789") == 0xCBF43926`, `adler32(b"Wikipedia") == 0x11E60398`.
- Hand-made streams: a fixed-Huffman block, a stored block, an empty input, and 10 malformed
  streams each returning the right error (no panics).
- `forall` (500 cases): random bytes (including long runs and repeats) round trip through
  `deflate`/`inflate` at every level 0..=9, and through `zlib_compress`/`zlib_decompress`.
- `forall` (1000 cases): random garbage and truncated/bit-flipped valid streams never panic in
  `inflate` or `decode_png`.
- PNG: `encode_png` then `decode_png` returns the same canvas (random sizes 1x1 to 70x50), and a
  handful of tiny hand-built PNGs (palette 1-bit, grey 16-bit with tRNS, Adam7 RGB) decode to
  hand-computed pixels.

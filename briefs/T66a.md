## Public API (exact)
```rust
// odyssey::style
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Display { Block, Inline, None }
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Len { Px(i32), Auto }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Computed { pub display: Display, pub width: Len, pub height: Len,
    pub margin: [Len; 4], pub padding: [i32; 4], pub border: [i32; 4],   // top, right, bottom, left
    pub color: [u8; 4], pub background: [u8; 4], pub font_px: i32 }
pub fn compute(doc: &Document) -> Vec<Option<Computed>>;   // indexed by NodeId; Some for elements only
// odyssey::layout
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct BoxRect { pub x: i32, pub y: i32, pub w: i32, pub h: i32 }
#[derive(Debug, Clone, PartialEq)]
pub struct TextRun { pub node: NodeId, pub text: String, pub rect: BoxRect, pub scale: u32 }
#[derive(Debug, Clone, PartialEq)]
pub struct Layout { pub boxes: Vec<(NodeId, BoxRect)>, pub runs: Vec<TextRun>, pub height: i32 }
pub fn layout(doc: &Document, styles: &[Option<Computed>], viewport_w: i32) -> Layout;
```
`boxes` holds the border box of every element with display Block, in document order. `runs` holds
every word fragment placed on a line, in order. `height` is the root's border-box height.

## Cascade (exact)
- Sources in order: the UA sheet below, then every `<style>` element's text (document order,
  `parse_stylesheet`), then each element's `style` attribute (`parse_declarations`). Winner per
  property: `!important` beats normal; then origin (style attribute > author > UA); then
  selector specificity; then later wins. Unknown properties and bad values are ignored.
- Properties: `display` (block, inline, none), `width`, `height` (`Npx` or `auto`), `margin`,
  `margin-*` (`Npx`, `auto`, or 0; shorthand with 1 to 4 values in CSS order), `padding`,
  `padding-*`, `border-width`, `border-*-width` (`Npx`, shorthand 1 to 4), `color`,
  `background-color` (`#rgb`, `#rrggbb`, `transparent`, and the names black white red green blue
  gray), `font-size` (`Npx`). Negative padding and border clamp to 0. A bare `0` is 0px.
- Initial values: display Inline, width/height Auto, margins 0, padding 0, border 0, color black
  `[0,0,0,255]`, background transparent `[0,0,0,0]`, font 16px. `color` and `font-size` inherit;
  the rest do not. Text nodes take their parent's values.
- UA sheet (verbatim): `html, body, div, p, h1, h2, h3, ul, ol, li, section, header, footer, nav,
  main, article, pre, blockquote { display: block } head, style, script, title { display: none }
  body { margin: 8px } p { margin: 16px 0 } h1 { font-size: 32px; margin: 21px 0 }
  h2 { font-size: 24px; margin: 19px 0 } ul, ol { margin: 16px 0; padding-left: 40px }`

## Layout (exact)
- The root is the `html` element (or the first element child of the document) with containing
  width `viewport_w` at (0, 0). Display None removes the element and its subtree.
- **Block width.** Content width = containing width - horizontal margins - borders - padding,
  where Auto margins count as 0; at least 0. A fixed `width` is the content width; then if both
  horizontal margins are Auto they split the slack equally (floor left), else an Auto margin takes
  all slack. Slack below 0 is 0.
- **Vertical.** Block children stack in order. Adjacent sibling vertical margins collapse to the
  larger of the two; no parent-child collapsing; Auto vertical margins are 0. Auto height is the
  sum of the children's stacked heights (margins included, collapsed) plus the line boxes.
- **Inline content.** A block whose children mix inline and block content wraps each maximal run
  of inline children in an anonymous block (no box reported). Text: collapse whitespace runs to
  one space; words are split at spaces; scale = `max(1, round(font_px / 16))` (half rounds up);
  a word's size is `pigment::text::measure(word, scale)`, a space is `8 * scale` wide. Words go on
  the current line while they fit in the content width; the first word on a line always goes
  (overflow allowed). Spaces at a line start are dropped. Line height = `16 * largest scale` on
  the line; every run is top-aligned. Inline elements only pass their style to their text.
- Boxes report border boxes: x and y of the margin edge plus margin, width = content + padding +
  border, height likewise. Use saturating arithmetic; nothing panics on any document.

## API (exact)
```rust
/// Counts of what one run changed.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Stats { pub folded: usize, pub copies: usize, pub removed: usize }
/// Optimise every `Body::Code` function in place; returns what changed. Idempotent in effect.
pub fn optimize(p: &mut mica::ir::Program) -> Stats;
```

## Passes (per function, repeat until nothing changes, at most 8 rounds)
1. Constant folding: `Un`/`Bin` whose operands are known `Lit::Int`/`Lit::Bool`/`Lit::Byte` constants (within a
   basic block) become `Lit`. Use the same semantics as the evaluator: an operation that would trap (overflow,
   divide or remainder by zero, `i64::MIN / -1`) is NOT folded. `Branch` on a known bool becomes `Jump`.
2. Copy propagation: after `Move(a, b)`, later reads of `a` in the same basic block read `b` until `a` or `b`
   is written again. Never across a `Label` (basic block start) or into a different block.
3. Dead code: remove instructions after `Jump`/`Ret` up to the next `Label`; remove pure instructions
   (`Lit`, `Move`, `Un`, non-trapping `Bin`, `New*`, `Tag`) whose destination register is never read anywhere in
   the function. Anything that can trap, call, write memory, or branch stays. Parameters are never removed.
- Keep `spans` parallel to `insts` (remove the span with its instruction). Never change `regs`, `params`, types
  or function order. `Extern` bodies are untouched.

## Tests (`tests/opt.rs`)
Differential: at least 300 random small programs (generate Mica source text from a seeded `assay::Rng`, check
and lower it with `mica::check::check(&mica::parser::parse(src)?)`, keep the ones that pass the checker), run with `mica::eval::run_main`
before and after `optimize`: same `Outcome` (value, output and trap kind). Plus unit tests for each pass,
including that trapping `Bin` ops are kept and that `optimize` run twice gives `Stats::default()` the second time.

## Tool
- `iridium`: a new bin `iridium` (keep `iridium-cli`): `sql DB [QUERY]` opens or creates a local database file (`FileStorage`) and runs one statement, or reads statements from stdin when QUERY is absent or `-`, printing result rows as tab-separated lines with a header; `connect ADDR` behaves like `iridium-cli`.

## Tests
`tests/cli_iridium.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input
each (exit 1 and a `iridium:` message), an unknown subcommand (exit 2). Run `cargo fmt -p iridium` before the gate.

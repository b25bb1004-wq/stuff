## Deliverables
- `src/bin/zeus.rs` (+ modules under `src/bin/zeus/`), `zeus.ld`, `build.rs` (link script only for the `zeus` bin).
- `src/lib.rs` host API:
  - `pub struct Guest { pub name: String, pub image: Image, pub size: u64, pub a1: u64 }` with
    `pub enum Image { Raw { bytes: Vec<u8>, gpa: u64 }, Elf(Vec<u8>) }` (ELF segments at their physical addresses,
    entry from the header; `Raw` entry = `gpa`).
  - `pub fn build_machine(zeus_elf: &[u8], guests: &[Guest]) -> Result<Machine, String>`: 64 MiB machine, zeus ELF
    loaded, each guest placed in slot `i` at `slot + (gpa - 0x8000_0000)`, boot table written. Errors (no machine) for 0
    or more than 3 guests, a bad name, a size that is 0, above 16 MiB or not a multiple of 2 MiB, a segment outside
    the guest's RAM, a bad ELF.
  - `pub fn split_console(out: &[u8]) -> BTreeMap<String, Vec<String>>`: lines grouped by `[<name>]` prefix, zeus's
    own lines under `"zeus"`.
- `README.md`: what runs, the memory map in one table, how to run the example.
- `examples/two_guests.rs`: boots lithium + titan and prints the console.

## Tests
- `tests/host.rs` (no riscv build): boot table bytes for a known input; every error case of `build_machine`;
  `split_console` on mixed lines.
- `tests/guests.rs` (builds zeus and titan ELFs like `crates/titan/tests/boot.rs`; lithium from `lithium::image()`):
  1. lithium alone (size 4 MiB): its `[lithium]` lines equal the lines of `lithium::run` on bare Silicon;
     `zeus: lithium exited 0`, `zeus: all guests done`, `Exit::Pass`.
  2. titan alone (size 16 MiB, `a1` = 16 MiB, no disk): `[titan]` lines equal titan's own output on bare Silicon with
     the same RAM size (boot it natively in the test); `Exit::Pass`.
  3. both together: each guest's lines equal its solo lines, in order; both exit lines; `Exit::Pass`.
  4. isolation: a `spy` guest (assembly in `tests/fixtures/spy.s`, built with `chisel::assemble` at `0x8000_0000`,
     size 2 MiB) next to lithium. Spy sets `mtvec` to a handler that counts faults and skips the instruction, then:
     loads from GPA `0x8020_0000` (just past its RAM), `0x8100_0000` and `0x8200_0000` (where other slots live in host
     memory), `0x8040_0000` (boot table), and `0x0` ; writes `csrw hgatp` and `csrr vsatp` (must trap); prints
     `spy: faults <n>` (expect 7) and exits 0. Assert spy's line, lithium's full solo transcript, and that lithium's slot
     bytes in host memory are unchanged except where lithium itself writes (compare its image region after the run with
     the run of test 1).
  5. a guest that faults with `mtvec = 0` is killed (`zeus: <name> killed: ...`) and the other guest still finishes;
     machine fails at the end (not every guest exited 0).

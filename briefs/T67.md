## Design (fixed by the leader)
- `paint::paint(doc, styles, layout, canvas)`: backgrounds (`background-color`), borders (solid, per side width and
  colour), text runs in `color` with the pigment font at the layout's scale, in document order (later boxes on top).
  Returns nothing; deterministic pixels.
- `fetch::get(url, limits) -> Result<Response, FetchError>`: `http://host[:port]/path` only (no TLS; `https` gives
  `Unsupported`). std `TcpStream` with connect/read timeouts (2 s), writes an HTTP/1.1 GET with `Host` and
  `Connection: close`, parses with `mercury::parse_response`, follows up to 5 redirects (301/302/303/307/308, relative
  `Location` resolved), caps the body at 8 MiB and headers as mercury's limits do. Errors are values, never panics.
- `script::run_page_scripts(doc, fuel) -> ScriptLog`: every `<script type="text/logos">` in document order, compiled and
  run like helios does. Externs (the whole page world, prefix `page.`): `page.text(id: str) -> str?`,
  `page.set_text(id: str, s: str) -> bool` (replaces the children of the element with that `id` by one text node),
  `page.log(s: str)`. A compile error or fuel exhaustion is logged and the page still renders. Default fuel 1_000_000.
  After scripts run, the cascade and layout are recomputed.
- `shell::Browser`: indium UI with an address field, Back, Reload, a status line and the page area (a pigment canvas
  painted by `paint`). `Browser::navigate(url)`, `back()`, `frame() -> &Canvas`. Links: clicking text inside `<a href>`
  navigates (resolve relative URLs). A failed fetch shows an error page, not a panic.

## Tests
- `tests/paint.rs`: 6 hand-written pages, each with exact pixel assertions at named points (background, border sides,
  first text pixel) and a 64-bit FNV hash of the whole canvas written as a constant.
- `tests/fetch.rs`: a `mercury::server` (or a raw `TcpListener` thread) on 127.0.0.1:0 serving: a page, a redirect chain,
  a redirect loop (error after 5), a 9 MiB body (error), a server that sends headers then stalls (timeout error),
  chunked encoding, a malformed status line. No test touches the internet.
- `tests/script.rs`: a page whose script sets a counter text, a script with a compile error, an infinite loop (fuel),
  and a script that sets text on a missing id (returns false). Assert the DOM text and the log.
- `tests/shell.rs`: serve 2 linked pages locally, navigate, click the link, Back, Reload; assert the URL history and a
  canvas hash per step. `assay::forall` of random clicks and keys over the Browser: never panics.
- `examples/browse.rs <url>`: fetch, run scripts, print the layout boxes and save nothing to disk.

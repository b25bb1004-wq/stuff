## Public API (exact; shapes are given in `docs/MBC.md`)
```rust
pub enum Value { Unit, Int(i64), Byte(u8), Bool(bool), Fn(u32), Ref(Handle) }   // Debug, Clone, Copy, PartialEq
pub struct Handle(pub u32);
pub enum Obj { Str(String), Bytes(Vec<u8>), Array(Vec<Value>), Record(Vec<Value>), Variant { tag: u32, fields: Vec<Value> } }
pub enum Trap { Overflow, DivideByZero, IndexOutOfRange, AssertFailed(String), TypeError,
                OutOfFuel, OutOfMemory, StackOverflow, Host(String), User(u32) }
pub struct Module { pub consts: Vec<Const>, pub imports: Vec<String>, pub funcs: Vec<Func>, pub entry: u32 }
pub enum Const { Str(String), Bytes(Vec<u8>) }
pub struct Func { pub name: String, pub params: u16, pub regs: u16, pub code: Vec<Op> }
pub enum Op { .. }                    // exactly the instruction table of docs/MBC.md, same names, same operand order
pub enum VerifyError { .. }           // one variant per rule, each carrying the function index and instruction index where it applies
pub fn verify(module: &Module) -> Result<(), VerifyError>;
pub enum DecodeError { BadMagic, Truncated, BadOpcode(u8), BadUtf8, TooLarge, Overlong }
pub fn encode(module: &Module) -> Vec<u8>;
pub fn decode(bytes: &[u8]) -> Result<Module, DecodeError>;
```
`Module`, `Func`, `Const`, `Op` derive `Debug, Clone, PartialEq`. Operand types: registers `u16`,
constant, function, import and tag indexes `u32`, jump targets `u32`, counts (`n`) `u16`.
Notes:
- `decode` must reject, before allocating, any count that could not fit in the bytes that remain
  (`TooLarge`), and any LEB128 number longer than its type allows (`Overlong`). It does not run
  `verify`; the two are separate steps.
- Opcode bytes are assigned in table order starting at 0; write them as explicit constants in one
  place (`opcode.rs`) so the numbering can never drift.
- `verify` implements every bullet of the "Verifier" section of the spec, including the limits.

## Tests required
- A generator of random valid modules (`forall`): every op kind appears; all indexes in range.
  For each: `verify` is `Ok`, and `decode(&encode(&m)) == Ok(m)`.
- One directed test per verifier rule: take a valid module, break exactly that rule, expect that
  exact `VerifyError` with the right function and instruction index.
- Decoder fuzz (`forall`, at least 3000 cases each): random bytes; a valid encoding with random
  bit flips; a valid encoding truncated at every length. Always `Ok` or `Err`, never a panic,
  and a 64-byte input never produces a module holding more than 64 instructions in total.
- LEB128: round trip of edge values (0, 127, 128, u32::MAX, i64::MIN, i64::MAX) and rejection
  of overlong encodings.

The opcode table read against the spec line by line, and the fuzz with a new seed.

## Public API (exact, re-exported from the crate root)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Edit { Keep(usize, usize), Delete(usize), Insert(usize) } // indices into a / b
/// Minimal edit script (Myers O(ND), linear-space refinement optional) turning `a` into `b`.
/// Deletes come before inserts inside each changed region.
pub fn diff<T: PartialEq>(a: &[T], b: &[T]) -> alloc::vec::Vec<Edit>;
/// Lines split on '\n' keeping the terminator; a last line without '\n' is a line too.
pub fn lines(text: &[u8]) -> alloc::vec::Vec<&[u8]>;
/// `git diff -U<context>` style hunks for two texts, with "--- a/<path>" / "+++ b/<path>"
/// headers and "\ No newline at end of file" markers. Empty output when equal.
pub fn unified(path: &str, a: &[u8], b: &[u8], context: usize) -> alloc::vec::Vec<u8>;
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Merged { pub text: alloc::vec::Vec<u8>, pub conflicts: usize }
/// diff3-style line merge of `ours` and `theirs` against `base`, as `git merge-file -p` with
/// labels "ours", "base", "theirs" and the default (merge) conflict style:
/// "<<<<<<< ours\n", our lines, "=======\n", their lines, ">>>>>>> theirs\n".
pub fn merge3(base: &[u8], ours: &[u8], theirs: &[u8]) -> Merged;
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Change { Added(String), Modified(String), Deleted(String) }
impl<S: Store> Repo<S> {
    /// Staged index vs HEAD tree, sorted by path; all Added when there is no commit.
    pub fn status(&self) -> alloc::vec::Vec<Change>;
    /// Merge branch or rev `other` into the current branch: fast-forward when possible, else a
    /// merge commit with parents [HEAD, other] when no file conflicts, else Err(MergeError::Conflict(paths))
    /// leaving HEAD and the index unchanged. Merge base = the newest common ancestor by committer time.
    pub fn merge(&mut self, other: &str, message: &str, who: &Signature) -> Result<Id, MergeError>;
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum MergeError { Repo(Error), Conflict(alloc::vec::Vec<String>), UpToDate }
```
## Behaviour
- `diff` is minimal: number of Delete + Insert equals `len(a) + len(b) - 2*LCS`.
- `merge3` matches `git merge-file -p ours base theirs` byte for byte for clean merges and for
  conflicts in the default style (git's zealous conflict trimming: lines common to both sides at
  the start and end of a conflict region are moved out of the markers). Both sides making the same
  change is not a conflict. `conflicts` counts marker blocks.
- Tree-level merge in `Repo::merge`: a file changed on one side only takes that side; changed on
  both is merged with `merge3`; added on both with different content or deleted on one side and
  modified on the other is a conflict.

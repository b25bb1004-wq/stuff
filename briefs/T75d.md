## Defect (seen by the leader in Chrome, 2026-11-16)
In the packed site, every iris example (default, second, and the error one) shows `unreachable`: the wasm panics.
The other five new demos work, and the native tests pass, so the cause is wasm-specific (for example `std::time`,
threads, a clock, a huge allocation, or deep recursion in a part of `iris` the demo calls).

## Fix
Find the call that panics on wasm32 (build `cargo build -p site --target wasm32-unknown-unknown --release` and
read what the demo reaches), then avoid it in the demo by calling a part of `iris` that works on wasm, or skip the
demo cleanly (remove it from the registry, the app and the launcher card back to "coming soon") and say why.
Add a test that runs the iris demo through the same entry point the wasm uses, if one is reachable natively.

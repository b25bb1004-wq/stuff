Worker: hydrogen-high (agy). Budget: one run, at most 150 minutes. First read `briefs/_RULES.md`, then
`docs/APPS.md` (the "Tool conventions" section and the table rows for these five; the rules there are part of this

**May touch:** in each of the five crates (and `crates/chisel` for the silicon tool) only `src/bin/<id>.rs`, `tests/cli.rs` and `Cargo.toml` (a `[[bin]]`

## Tools
- `sphinx`: `hash ALG FILE` (sha256, sha512; hex), `hmac KEYHEX FILE`, `keygen -o KEYFILE` (ed25519; seed: 32 bytes from `/dev/urandom` where it exists, else from four
  `std::collections::hash_map::RandomState` hashes, which std seeds from the OS; key file written mode 600 on unix),
  `sign KEYFILE FILE` (signature hex), `verify PUBHEX SIGHEX FILE` (exit 0 or 1), `seal`/`open` with a 32-byte key
  file if the library offers an AEAD; known-answer tests use published vectors (sha256 of "abc").
- `silicon`: `run ELF [--steps N] [--ram MiB] [--trace]`: chisel depends on silicon, so this bin lives in `crates/chisel/src/bin/silicon.rs`
  (with `crates/chisel/tests/cli_silicon.rs`) and loads with `chisel::elf::{read, load}`; run, UART output to stdout, then
  `exit: <Exit>` and `instret: N`; `--trace` prints `pc inst` lines up to 1000. Test with an ELF built in the test
  by `chisel::assemble` (dev-dep) that prints `hi` and exits.
- `hades`: `mkfs IMG [--blocks N]`, `ls IMG PATH`, `cat IMG PATH`, `put IMG SRC PATH`, `rm IMG PATH`,
  `mkdir IMG PATH`, `fsck IMG` (prints errors, exit 1 if any). The image is a plain file used through `MemDisk`
  (read whole, write back atomically: temp file then rename).
- `mercury`: `parse FILE` (raw request or response; prints fields), `serve DIR [--listen 127.0.0.1:8080]`
  (static files via `Router::static_dir`, Ctrl+C stops), `get http://HOST[:PORT]/PATH` (plain HTTP only; https
  gives exit 1 `mercury: https not supported`). Test `serve` on a free port in the test with a thread and
  `TcpStream`, then `get` against it.
- `elysium`: `verify FILE.mbc`, `dis FILE.mbc` (one instruction per line with offsets), `run FILE.mbc
  [--fuel N]` (result and steps). Tests build a small module with the library's own encoder.

subcommand exit 2). Gate each crate: `bash tools/check.sh <crate>` for all five.

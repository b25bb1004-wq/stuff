## Public API (re-exported at the crate root, exact)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Tree(/* private: the root page number */);
impl Tree {
    pub fn create<S: Storage>(p: &mut Pager<S>) -> Result<Tree, Error>; // allocates an empty root leaf
    pub fn open(root: u64) -> Tree;
    pub fn root(&self) -> u64;
    pub fn get<S: Storage>(&self, p: &mut Pager<S>, at: Option<Snapshot>, key: &[u8])
        -> Result<Option<Vec<u8>>, Error>;
    pub fn insert<S: Storage>(&self, p: &mut Pager<S>, key: &[u8], value: &[u8])
        -> Result<Option<Vec<u8>>, Error>;            // replaces; returns the old value
    pub fn remove<S: Storage>(&self, p: &mut Pager<S>, key: &[u8]) -> Result<Option<Vec<u8>>, Error>;
    pub fn scan<S: Storage>(&self, p: &mut Pager<S>, at: Option<Snapshot>, from: Bound<&[u8]>,
        f: &mut dyn FnMut(&[u8], &[u8]) -> bool) -> Result<(), Error>; // ascending; stop when f is false
    pub fn range<S: Storage>(&self, p: &mut Pager<S>, at: Option<Snapshot>, lo: Bound<&[u8]>,
        hi: Bound<&[u8]>) -> Result<Vec<(Vec<u8>, Vec<u8>)>, Error>;  // empty if lo > hi
    pub fn destroy<S: Storage>(self, p: &mut Pager<S>) -> Result<(), Error>; // frees every page
}
```
`Bound` is `std::ops::Bound`. `at: None` reads the pager's current view (the open transaction's
if one is open); `Some(snap)` reads through `Pager::read_snapshot`.

## Rules
- Formats exactly as IRIDIUM.md section 2: 16-byte header (kind 2 interior / 3 leaf, flags 0, cell
  count, cell-content start, fragmented bytes, `link`), u16 offsets in key order, cell bodies
  growing down from byte 4092 (the first cell of an empty page ends at 4092), leaf cells with the
  1200-byte inline rule and overflow pages (kind 4, next at byte 16, data 24..4092), interior cells
  `child u64, varint klen, key`, minimal LEB128 varints. Defragment a page when a cell does not
  fit in the gap but fits in the free total.
- The root page number never changes: a root split moves the root's content to new pages and the
  root becomes an interior page; when an interior root is left with one child, the child's content
  moves into the root and the child page is freed.
- Separators: any key `s` with (every key in child i) `< s <=` (every key in child i+1); a shorter
  separator is allowed. Interior pages have at least 1 cell; non-root leaves at least 1 cell.
- Remove: an empty non-root page is freed and dropped from its parent. After a remove, if the
  touched page and its left (then right) sibling under the same parent fit together in one page
  (cell bytes + 2 per offset <= 4076; for interior pages include the pulled-down separator), merge
  them and free one page. A removed or replaced value's overflow pages are freed at once.
- Every page that leaves a tree goes to the pager free list (`Pager::free`); no page leaks:
  page 0 + all tree pages + the free list = `page_count`.
- Errors: key longer than 1024 bytes (insert, get, remove, scan bound) or value longer than
  1 MiB (`1 << 20`) is `TooLarge` (both limits inclusive); `create`, `insert`, `remove` and
  `destroy` outside a transaction are `Misuse`, even when nothing would change.
  Hostile page contents (bad kind, offsets or lengths out of range, unsorted keys, a walk deeper
  than 32 levels, an overflow chain longer than its value needs, a leaf chain longer than
  `page_count`) are `Corrupt`, never a panic or a hang.

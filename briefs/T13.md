## How a test reports
Each line of `index.txt` is `<name> <tohost address, hex> <size>`. Load `<name>.bin` at `RAM_BASE`
(1 MiB RAM is enough), run; the test writes a non-zero u64 to `tohost`: 1 = pass, otherwise
`(failing test number << 1) | 1`. Read it with `m.board.read(tohost, 8)` (the `Bus` trait). Run in
chunks (e.g. 10 000 steps) until `tohost` is non-zero, at most 5 000 000 steps.

## Changes
1. **Misaligned loads and stores** (LB..LD, SB..SD, and the compressed forms) no longer trap:
   the access is done byte by byte, little-endian, each byte translated on its own (so it may
   cross a page). Translate every byte first; if any byte faults, raise that fault with the
   virtual address of the first faulting byte as tval and change nothing (no partial store). LR,
   SC and AMOs keep trapping on misalignment exactly as now. Aligned accesses keep their current
   single bus access (devices see the same widths as before). Update the doc comments that say
   misaligned accesses trap (T12's rule is replaced by this one).
2. **Counter writes win:** an instruction that writes `minstret` (or `mcycle`) does not also
   count itself in that counter, so the next read sees the written value (the reading
   instruction counts after it reads).
3. **PMP registers as storage:** `pmpcfg0` (0x3A0), `pmpcfg2` (0x3A2) and `pmpaddr0..15`
   (0x3B0..0x3BF) read and write. `pmpaddr` keeps bits 53..0 (granularity 0); `pmpcfg` keeps
   every byte as written except bits 6..5 of each byte (reserved, read 0). No checking of accesses
   against PMP (machine mode is unaffected; document this as a known gap). `pmpcfg1/3` (odd) do
   not exist on RV64 and trap as illegal.

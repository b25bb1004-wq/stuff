## Public API (exact; Machine (T23), Flint, Mantle and Bedrock are written against it)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Mode { User, Supervisor, Machine }
// Trap gains: InstPageFault(u64), LoadPageFault(u64), StorePageFault(u64),
//             LoadMisaligned(u64), StoreMisaligned(u64). Ecall stays one variant (cause from mode).
impl Trap { pub fn cause(&self, mode: Mode) -> (u64, u64); }  // (mcause code, mtval)
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Step { Retired, Exception(Trap), Interrupt(u64), Wfi }   // what `tick` did
pub struct Cpu { pub x: [u64; 32], pub pc: u64, pub instret: u64, pub mode: Mode, /* private CSR file */ }
impl Cpu {
    pub fn new(pc: u64) -> Cpu;                       // Machine mode, satp bare, all CSRs at reset values
    pub fn step(&mut self, bus: &mut impl Bus) -> Result<(), Trap>;  // as T03: an exception is RETURNED, not taken
    pub fn run(&mut self, bus: &mut impl Bus, max_steps: u64) -> Result<(), Trap>;  // unchanged
    pub fn tick(&mut self, bus: &mut impl Bus) -> Step;  // full hart: takes a pending enabled interrupt or an
                                                         // exception into the handler (with delegation)
    pub fn csr_read(&self, addr: u16) -> Option<u64>;   // host/debug access, no privilege check; None = no such CSR
    pub fn csr_write(&mut self, addr: u16, value: u64) -> bool;  // applies WARL masks; false = no such CSR
    pub fn set_pending(&mut self, bit: u8, on: bool);   // mip bits 1 SSIP, 3 MSIP, 5 STIP, 7 MTIP, 9 SEIP, 11 MEIP
    pub fn translate(&mut self, bus: &mut impl Bus, vaddr: u64, access: Access) -> Result<u64, Trap>;
}
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Access { Fetch, Load, Store }
```
`inst::Inst` gains `Csrrw Csrrs Csrrc { rd, rs1, csr: u16 }`, `Csrrwi Csrrsi Csrrci { rd, uimm: u8, csr: u16 }`,
`Mret`, `Sret`, `Wfi`, `SfenceVma { rs1, rs2 }` (keep `Fence`/`FenceI` if present; `FenceI` is a no-op).
`decode` and `encode` handle all of them; `encode(decode(w)) == w` for every valid word.

## Behaviour
- CSRs: `mstatus` (MIE MPIE MPP SIE SPIE SPP SUM MXR MPRV TVM TW TSR; UXL/SXL read 2),
  `misa` (RV64 + I M S U, writes ignored), `mvendorid marchid mimpid mhartid` (0), `medeleg`,
  `mideleg`, `mie`, `mip`, `mtvec` (direct and vectored), `mscratch mepc mcause mtval`,
  `mcounteren scounteren`, `sstatus sie sip` as masked views, `stvec sscratch sepc scause stval`,
  `satp` (modes Bare and Sv39 only; other mode values leave satp unchanged), `mcycle minstret`
  and the read-only `cycle time instret` (`time` reads a value the host sets with
  `csr_write(0xC01, ..)`; give it a field). PMP CSRs read 0 and ignore writes.
- CSR access checks: privilege level from address bits 9:8, read-only from bits 11:10, counter
  enables, `TVM` for satp and sfence.vma in S, `TW` for wfi, `TSR` for sret. Violations raise
  IllegalInstruction with the instruction word as tval.
- Traps: exceptions and interrupts go to M unless delegated by `medeleg`/`mideleg` and the hart
  is in S or U. Set `xepc`, `xcause`, `xtval`, `xPP`, `xPIE`, clear `xIE`, jump to `xtvec`
  (vectored adds 4 * cause for interrupts). `mret`/`sret` restore. Interrupt priority:
  MEI, MSI, MTI, SEI, SSI, STI. An interrupt is taken only when enabled for the target mode by the
  spec rules (always for a lower current mode). Ecall cause 8/9/11 by mode. Ebreak tval = pc.
- Sv39: 3-level walk, superpages (misaligned superpage is a page fault), R/W/X/U checks with
  SUM and MXR, `MPRV` for M-mode loads and stores, reserved W-without-R is a fault, upper bits
  of the virtual address must equal bit 38. Accessed and Dirty bits: the hardware sets them
  (write the PTE back). A failed walk gives the page fault for the access kind, tval = vaddr.
- Misaligned loads and stores of 2, 4, 8 bytes raise LoadMisaligned or StoreMisaligned (no
  emulation). A page-crossing access is not possible then.
- `wfi` in `tick` returns `Step::Wfi` (pc advanced) when no interrupt is pending; the caller decides.
- No panic on any instruction word, CSR value or page table content.

## Tests required
- Unit tests per CSR (WARL masks, views, read-only and privilege traps).
- Trap tests with hand-encoded programs: ecall from each mode, delegated and not, mret and sret
  round trips, vectored mtvec, interrupt priority and masking, wfi.
- Sv39 with page tables built in RAM by the test: 4 KiB, 2 MiB and 1 GiB pages, every
  permission fault, SUM, MXR, MPRV, A/D update, non-canonical address.
- Property: `forall` random words decode then encode equal (or decode errors), random page
  tables never panic the walker, random CSR writes then reads stay inside the WARL masks.

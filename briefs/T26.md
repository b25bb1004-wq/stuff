## Host-testable modules in `src/lib.rs` (no asm; unit tests plus a `forall` each)
- `pub mod elf`: parse an ELF64 RISC-V executable from bytes: `pub fn parse(bytes: &[u8]) -> Result<Program, ElfError>`
  with `Program { entry: u64, segments: Vec<Seg { vaddr, file: Range<usize>, mem_size, r, w, x }> }`. Reject: bad magic,
  not ELF64/LE/RISC-V/EXEC, truncated headers or segments, file size > mem size, overlapping segments, any segment or
  entry outside user space `0x1_0000..0x3F_FFFF_F000`, or address overflow. Never panic on any input (forall over
  random and mutated chisel-written images).
- `pub mod uaccess`: `pub fn check_user_range(ptr: u64, len: u64) -> Result<(), Errno>` (whole range inside user space,
  no overflow; len 0 is Ok) and `pub enum Errno` with the MANTLE.md codes (-1..-7) and `as_isize()`.
- `pub mod proc`: process table logic without hardware: pids from 1, states (Runnable, Running, Blocked(Wait), Zombie),
  parent links, `spawn`, `exit(code)`, `wait(parent, pid) -> Result<exit code | WouldBlock, Errno>` (only a child; reaping
  frees the slot), `kill(pid)` (exit code -1), orphans re-parented to pid 1, `ps()` rows. A shadow-model forall.

## Kernel
- After the T25 self-test prints `boot ok`, the kernel loads the built-in program `init` and enters user mode
  (U-mode, `sret`). Each process: its own Sv39 root with the kernel mappings (`U = 0`) plus its segments (`U = 1`, R/W/X
  from the ELF), a 16 KiB user stack ending at `0x3F_FFFF_F000`, a heap grown by `sbrk` from the page after the highest
  segment, a kernel stack and trap frame. `sstatus.SUM` stays 0; the kernel reads user memory only through helpers that
  walk the process table and check `U` and permissions.
- Scheduling: geyser `Scheduler` (1 CPU) picks on every timer tick and on `yield`, `wait` (blocking) and `exit`.
- Syscalls (numbers and errors exactly as MANTLE.md): exit, write (fd 1 and 2 to the UART), read (fd 0: returns 0 when
  no input), getpid, yield, sbrk (negative shrinks and unmaps, frees frames), spawn (path = a built-in program name;
  argv may be empty), wait, kill, ps (writes `pid state name` lines into the buffer, returns bytes written), uptime
  (ticks). open, close, mkdir, unlink, readdir return -2 until T27. Unknown numbers return -1. Bad user pointers return
  -1 and never fault the kernel.
- A user page fault or illegal instruction kills the process with exit code -1 and the kernel prints
  `kill pid <n>: <load|store|fetch|illegal> fault at 0x<addr>`.
- When init exits the kernel prints `init exited <code>`, then `frames <n> free` where n must equal the free-frame
  count just before init was created (no leaks), then writes `0x5555` to the finisher (`(1 << 16) | 0x3333` if init's
  code is not 0 or frames leaked).

## Built-in user programs (RV64 assembly in `crates/mantle/user/*.s`)
`build.rs` assembles each with `chisel::assemble(src, 0x1_0000)`, wraps it with `chisel::elf::write` (one R+X text
segment, one R+W data segment if the program has data), and the kernel embeds the ELFs (`include_bytes!` from OUT_DIR)
in a name table: `init`, `ping`, `pong`, `hog`, `fault`, `evil`.
- `ping` / `pong`: print `ping <i>` / `pong <i>` for i in 0..5, with a busy loop between lines long enough to cross
  several timer ticks; exit 7 / 9.
- `hog`: sbrk 1 MiB, write one byte per page, read them back, print `hog: sbrk ok`, sbrk(-1 MiB), exit 0.
- `fault`: load from address 0 (the kernel kills it).
- `evil`: `write(1, 0x8000_0000, 16)` must return -1, `write(1, 0x3F_FFFF_FF00, 4096)` must return -1, `kill(1)` from a
  non-parent is allowed only for its own children (returns -1 here), then print `evil: rejected`, exit 3.
- `init`: print `init: hello pid 1`; spawn ping and pong, wait both and print `init: ping exited 7`, `init: pong exited 9`;
  then spawn and wait `hog`, `fault`, `evil` in turn, printing `init: <name> exited <code>`; call ps and print its
  buffer; print `init: uptime ok` if uptime > 0; exit 0.

## Why

(T64) use it. Expansion must match POSIX `sh` (as `bash --posix` does) word for word.

## Public API (exact; add private helpers freely)
```rust
pub mod ast {
    pub type Word = Vec<Part>;
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub enum Part {
        Lit(String),            // unquoted text (may hold glob characters)
        Single(String),         // '...'
        Escaped(char),          // backslash outside quotes
        Double(Vec<Part>),      // "...": holds Lit, Escaped, Param, Cmd, Arith only
        Param(Param),           // $x ${x} ${x:-w} ...
        Cmd(Script),            // $(...) and `...`
        Arith(String),          // $((...)), raw text, expanded at run time
        Tilde(String),          // ~ or ~user at word start (or after = / : in assignments)
    }
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct Param { pub name: String, pub op: ParamOp } // name: identifier, digit(s), or one of @*#?$!-
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub enum ParamOp { Plain, Length,
        Default(bool, Word), Assign(bool, Word), Error(bool, Word), Alt(bool, Word), // bool = colon form
        TrimSuffix(bool, Word), TrimPrefix(bool, Word) }                            // bool = longest (%% / ##)
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub enum RedirOp { In, Out, Append, Clobber, ReadWrite, DupIn, DupOut,
                       HereDoc { strip_tabs: bool, quoted: bool, body: Word } } // body unexpanded if quoted: one Lit
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct Redir { pub fd: Option<u32>, pub op: RedirOp, pub target: Word } // target empty for HereDoc
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct Simple { pub assigns: Vec<(String, Word)>, pub words: Vec<Word>, pub redirs: Vec<Redir> }
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub enum Command {
        Simple(Simple),
        Subshell(Script, Vec<Redir>),
        Group(Script, Vec<Redir>),
        If { arms: Vec<(Script, Script)>, otherwise: Option<Script>, redirs: Vec<Redir> },
        Loop { until: bool, cond: Script, body: Script, redirs: Vec<Redir> },
        For { var: String, words: Option<Vec<Word>>, body: Script, redirs: Vec<Redir> },
        Case { word: Word, arms: Vec<(Vec<Word>, Script)>, redirs: Vec<Redir> },
        Func { name: String, body: Box<Command> },
    }
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct Pipeline { pub bang: bool, pub cmds: Vec<Command> }
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct AndOr { pub first: Pipeline, pub rest: Vec<(bool, Pipeline)>, pub background: bool } // true = &&
    #[derive(Debug, Clone, PartialEq, Eq, Default)]
    pub struct Script { pub items: Vec<AndOr> }
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ParseError { pub line: u32, pub col: u32, pub msg: String, pub incomplete: bool }
pub fn parse(src: &str) -> Result<ast::Script, ParseError>; // incomplete = input ended inside a construct

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ExpandError { Unset(String, String) /* ${x?msg} */, BadSubst(String), Arith(String) }
pub trait Env {
    fn get(&self, name: &str) -> Option<String>;     // shell variables and $? $$ $! $- $0
    fn set(&mut self, name: &str, value: &str);       // used by ${x=w} and arithmetic assignment
    fn positional(&self) -> Vec<String>;             // $1.. ; $# $@ $* derive from this
    fn command(&mut self, s: &ast::Script) -> String; // stdout of a command substitution
    fn home(&self, user: &str) -> Option<String>;    // "" = current user
    fn list_dir(&self, dir: &str) -> Vec<String>;    // entry names (no . or ..), any order
}
pub fn expand(words: &[ast::Word], env: &mut dyn Env) -> Result<Vec<String>, ExpandError>;
pub fn expand_one(word: &ast::Word, env: &mut dyn Env) -> Result<String, ExpandError>; // no split, no glob
pub fn arith(expr: &str, env: &mut dyn Env) -> Result<i64, ExpandError>;
pub fn glob_match(pattern: &str, name: &str) -> bool; // * ? [abc] [a-z] [!x] [^x], backslash escapes
```

## Behaviour (POSIX XCU 2.2 to 2.10, 2.13)
- Tokens: operators `&& || ; & | ( ) < > >> <& >& <> >| << <<-`, newlines, `#` comments,
  reserved words only in command position (`if then elif else fi do done case esac while until
  for in { } !`). Line continuation `\<newline>` removed outside single quotes. Here-doc bodies
  are read after the line that names them, several per line, in order.
- `expand` order: tilde, parameter, command substitution (trailing newlines removed),
  arithmetic; then field splitting by `IFS` (unset = space tab newline; IFS whitespace collapses,
  other IFS characters delimit, empty IFS = no split) on unquoted results only; then pathname
  expansion of fields with unquoted `* ? [`; then quote removal. `"$@"` gives one field per
  positional (zero fields when there are none); `"$*"` joins with the first IFS character.
  Empty unquoted results vanish; `""` stays one empty field.
- Globbing: pattern split on `/`; each component matched with `glob_match` against
  `env.list_dir`; a leading `.` in a name only matches a literal `.`; results sorted by byte order;
  no match leaves the word unchanged (quotes removed). Only components with glob characters list
  directories.
- Arithmetic: i64, C precedence for `+ - * / % << >> < <= > >= == != & ^ | && || ! ~ ?:`, unary
  minus, parentheses, decimal / `0x` / leading-0 octal, variables by name (unset or empty = 0),
  `= += -= *= /= %=` assignment through `Env::set`; divide by zero is `ExpandError::Arith`;
  overflow wraps.
- Never panic on any input; `parse` of arbitrary bytes returns Ok or Err.

## Why
Strata installs its own software from its own registry, and a package that was changed after
signing must never be installed (PLAN: "tampered package is refused"). T52 ships container images
as cairn packages.

## Public API (new modules, exact)
```rust
pub mod pkg {
    use crate::manifest::Manifest;
    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct Package { pub manifest: Manifest, pub files: Vec<(String, Vec<u8>)> }

    pub fn encode(p: &Package) -> Vec<u8>;                    // body, see format
    pub fn decode(body: &[u8]) -> Result<Package, PkgError>;
    pub fn sign(p: &Package, seed: &[u8; 32]) -> Vec<u8>;     // signed blob
    pub fn open(blob: &[u8], trusted: &[[u8; 32]]) -> Result<Package, PkgError>;
}
pub mod registry {
    pub struct Registry { /* private */ }
    impl Registry {
        /// Serves the protocol below on `addr` (e.g. "127.0.0.1:0"); accepts uploads signed by
        /// any of `publishers`. In memory; packages are immutable once published.
        pub fn start(addr: &str, publishers: Vec<[u8; 32]>) -> std::io::Result<Registry>;
        pub fn addr(&self) -> std::net::SocketAddr;
        pub fn stop(self);
    }
}
pub mod client {
    use crate::{pkg::PkgError, solve::{Solution, SolveError}, version::Req};
    #[derive(Debug)]
    pub enum InstallError {
        Http(String), Solve(SolveError), Package(String, PkgError), Io(std::io::Error),
        NotInstalled(String), InUse(Vec<String>),
    }
    pub fn install(registry: std::net::SocketAddr, deps: &[(String, Req)], root: &std::path::Path,

    pub fn installed(root: &std::path::Path) -> Result<Solution, InstallError>;
}
```

## Package format (exact; the leader check builds blobs on its own)
All integers little-endian.
```
body := "CAIRNPKG1\n" | u32 len | manifest text (len bytes, = manifest.to_string())
        | u32 count | count x ( u16 plen | path (plen bytes UTF-8) | u32 dlen | data )
blob := "CAIRNSIG1\n" | public key (32) | signature (64) = ed25519::sign(seed, body) | body
```
- `encode` writes files sorted by path bytes. `decode` requires strictly increasing paths (sorted,
  no duplicates), no trailing bytes, a manifest that `Manifest::parse` accepts and whose
  `to_string()` equals the stored text; otherwise `Malformed`. So `encode(&decode(b)?) == b`.
- Paths: `/`-separated, 1..=255 bytes, every component non-empty and not `.` or `..`; no leading
  `/`, no `\`, no `:`, no NUL, no control characters. Otherwise `BadPath(path)`. `encode` and
  `sign` may panic on such a package (caller error); `decode`/`open` must return the error.
- `open` checks, in this order: magic and minimum length (`Malformed`), key in `trusted`
  (`UntrustedKey`), signature over the whole body (`BadSignature`), then `decode`.

## Registry protocol (HTTP/1.1 via outcrop's server; set `max_body` to 64 MiB)
- `PUT /pkg/<name>/<version>`, body = blob. 201 on success. 400 if `decode` fails, the path is bad,
  or the URL name/version differ from the manifest. 403 if the key is not a publisher or the
  signature fails. 409 if that name and version already exist (even with identical bytes).
- `GET /pkg/<name>/<version>`: 200 with the blob byte for byte as uploaded; 404 if absent.
- `GET /index`: 200, one line per published version, sorted by name then version:
  `name \t version ( \t dep \t req )* \n` with deps in manifest order, `req` = `Req`'s Display.
  Empty registry: empty body.
- Anything else: 404 (unknown path) or 405 (known path, wrong method).

## Client
- Talks HTTP with `std::net::TcpStream` + `outcrop::write_request`/`parse_response`
  (`Connection: close` is fine). Non-2xx is `Http(..)` with the status.
- Layout under `root`: `cairn.lock` (`lock::write` of the installed solution),
  `pkgs/<name>-<version>/<path>` (the package files), `pkgs/<name>-<version>.manifest`.
- `install`: fetch `/index`, `solve(index, deps, existing lock)` (keeps locked versions when they
  still fit), then download and `open` every package that is not already installed at that version.
  The opened manifest must name exactly the requested name and version, else
  `Package(name, Malformed(..))`. Only after every package verified: write the new packages,
  delete packages that are installed but not in the new solution, write `cairn.lock`. If anything
  fails before that point, `root` is left exactly as it was (no new files or directories, lock
  unchanged). Never write outside `root`. Returns the solution.
- `remove`: `NotInstalled` if `name` is not installed; `InUse(dependents, sorted)` if another
  installed package depends on it; otherwise delete its directory and manifest and rewrite the lock.
- `installed`: the solution in `cairn.lock` (empty if there is no lock).

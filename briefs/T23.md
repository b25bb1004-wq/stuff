## Why
Lithium/Titan/Zeus boot an OS on this board: a console, a timer, interrupts, a disk, a screen
and keys. Layout follows the usual RISC-V "virt"-style boards so OS code ports over.

## Public API (exact, `silicon::machine`)
```rust
pub const RAM_BASE: u64 = 0x8000_0000;
pub struct Config { pub ram_size: usize, pub disk: alloc::vec::Vec<u8>, pub fb_width: u32, pub fb_height: u32 }
impl Default for Config {}          // 16 MiB RAM, empty disk, 320 x 240
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Exit { Pass, Fail(u32), OutOfSteps }
pub struct Board { /* RAM + devices */ }
impl Bus for Board {}               // MMIO reads/writes have their device side effects
impl Board {
    pub fn uart_input(&mut self, bytes: &[u8]);        // queue bytes for the guest to read (unbounded)
    pub fn take_uart_output(&mut self) -> alloc::vec::Vec<u8>;  // drain bytes the guest wrote
    pub fn press_key(&mut self, code: u32);             // push to the key FIFO (64 deep; extra keys dropped)
    pub fn framebuffer(&self) -> &[u8];                 // fb_width * fb_height * 4 bytes, RGBA
    pub fn disk(&self) -> &[u8];
    pub fn mtime(&self) -> u64;
}
pub struct Machine { pub cpu: Cpu, pub board: Board }
impl Machine {
    pub fn new(cfg: Config) -> Machine;                  // Cpu::new(RAM_BASE), M-mode
    pub fn load(&mut self, addr: u64, data: &[u8]) -> Result<(), Fault>;  // into RAM
    /// One tick: mtime += 1; sample every device's interrupt line into the PLIC; set the hart's
    /// MTIP, MSIP, MEIP, SEIP from CLINT/PLIC state (set_pending); then `cpu.tick(&mut board)`.
    pub fn step(&mut self) -> Step;
    /// Step until the test finisher is written (Pass / Fail(value >> 16)) or `max_steps` ran.
    pub fn run(&mut self, max_steps: u64) -> Exit;
}
```
## Memory map and devices (exact)
Accesses outside every device -> `Fault::Unmapped(addr)`; an access running past a device's end
or RAM's end -> `Err`. Undefined offsets inside the CLINT/PLIC/UART/block/keys/display windows read 0
and ignore writes.
- **Test finisher** `0x0010_0000` (4 bytes): 32-bit write 0x5555 -> Pass; low 16 bits 0x3333 ->
  Fail(value >> 16). Other values ignored.
- **CLINT** `0x0200_0000` (size 0x10000): msip u32 at +0 (bit 0 -> MSIP); mtimecmp u64 at +0x4000
  (reset u64::MAX); mtime u64 at +0xBFF8 (reset 0, +1 per `step`, writable). 4-byte accesses to
  either half and 8-byte accesses work. MTIP = mtime >= mtimecmp.
- **PLIC** `0x0C00_0000` (size 0x400_0000), sources 1..=31, context 0 = M, context 1 = S, all
  registers u32 (other sizes -> Err): priority at +4*id (3 bits, source 0 reads 0); pending bits
  at +0x1000 (read only); enables at +0x2000 (ctx 0) and +0x2080 (ctx 1); threshold at
  +0x20_0000 / +0x20_1000; claim/complete at +0x20_0004 / +0x20_1004.
  Level gateway: each `step`, a source whose line is high and that is not in flight becomes pending
  (pending stays set until claimed). Claim returns the pending source enabled in that context with
  the highest priority greater than the threshold (ties: lowest id), clears its pending bit and
  marks it in flight; nothing eligible -> 0. Writing an id that is in flight and enabled in that
  context completes it; other writes are ignored. MEIP / SEIP = context 0 / 1 has an eligible source.
- **UART** `0x1000_0000` (8 registers, byte accesses only, other sizes -> Err), 16550 subset, PLIC
  source 10: +0 read RBR (pop RX byte, 0 if empty) / write THR (append to output); +1 IER (bit 0 RX
  interrupt, bit 1 TX-empty interrupt); +2 read IIR = 0xC4 if RX interrupt active, else 0xC2 if
  bit 1 set, else 0xC1 (write = FCR, ignored); +3 LCR, +4 MCR, +7 SCR plain read/write;
  +5 LSR = 0x60 | (RX non-empty as bit 0); +6 MSR reads 0. Line = (IER.0 and RX non-empty) or IER.1.
- **Block** `0x1000_1000` (size 0x1000), 512-byte sectors, PLIC source 8: +0x00 u64 sector,
  +0x08 u64 DMA address, +0x10 u32 count, +0x14 u32 command (write 1 = disk -> RAM, 2 = RAM -> disk;
  runs at once), +0x18 u32 status (0 ok, 1 error: sectors past the disk end or DMA range not wholly
  in RAM; on error nothing is copied), +0x1C u32 irq enable, +0x20 u32 done (set by every command;
  any write clears it), +0x28 u64 capacity in sectors (read only). Line = irq enable and done.
- **Keys** `0x1000_2000` (size 0x1000), u32 registers, PLIC source 11: +0 count (read only), +4 pop
  oldest code (0 when empty), +8 irq enable. Line = irq enable and count > 0.
- **Display** `0x1000_3000`: u32 width at +0, height at +4 (read only). Framebuffer
  `0x3000_0000`, width * height * 4 bytes, plain memory, pixel (x, y) at 4 * (y * width + x),
  bytes R, G, B, A.
- **RAM** at `RAM_BASE`, `ram_size` bytes.

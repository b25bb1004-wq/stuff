## Public API (exact, `chronos::remote`, feature `std`)
```rust
#[derive(Debug)]
pub enum RemoteError { Io(String), Http(u16), Protocol, Rejected(String), Repo(Error), Merge(MergeError) }
/// Pack: b"DPK1", u32 BE object count, then per object: kind byte (1 blob, 2 tree, 3 commit),
/// u32 BE length, raw object bytes (the same bytes `Repo::put` hashes); then the 32-byte
/// SHA-256 of everything before it.
pub fn encode_pack(objects: &[(Kind, Vec<u8>)]) -> Vec<u8>;
pub fn decode_pack(pack: &[u8], max_objects: usize) -> Result<Vec<(Kind, Vec<u8>)>, RemoteError>;
/// Mount the protocol under `prefix` (e.g. "/repo") on an mercury router:
///   GET  {prefix}/refs  -> 200, body lines "<64 hex> <branch>\n" sorted by branch name
///   POST {prefix}/fetch -> body lines "want <hex>\n" and "have <hex>\n"; 200 with a pack of every
///        object reachable from the wants and NOT reachable from any have the server knows
///   POST {prefix}/push  -> body: lines "<old hex or 64 zeros> <new hex> <branch>\n", one empty
///        line, then a pack; reply 200 with one line per ref: "ok <branch>\n" or "ng <branch> <reason>\n"
pub fn serve<S: Store + Send + 'static>(repo: std::sync::Arc<std::sync::Mutex<Repo<S>>>,
                                        router: &mut mercury::server::Router, prefix: &str);
/// `url` is "http://host:port/prefix".
pub fn clone<S: Store>(url: &str, store: S) -> Result<Repo<S>, RemoteError>; // all branches; checks out "main" if present
impl<S: Store> Repo<S> {
    /// Download missing objects for every remote branch; returns the remote refs. Local branches unchanged.
    pub fn fetch(&mut self, url: &str) -> Result<Vec<(String, Id)>, RemoteError>;
    /// fetch, then `merge` the remote `branch` tip into the current branch (fast-forward when possible).
    pub fn pull(&mut self, url: &str, branch: &str, who: &Signature) -> Result<Id, RemoteError>;
    /// Send the local `branch` (objects the server lacks, using its refs as haves); fast-forward only.
    pub fn push(&mut self, url: &str, branch: &str) -> Result<(), RemoteError>; // "ng" -> Err(Rejected(reason))
}
```
## Behaviour
- Server, per push ref line, under the repository lock: the ref update is applied only if
  (1) `old` equals the server's current value (64 zeros = branch must not exist) else
  `ng <b> stale`; (2) every object in the pack hashes to an id and the new commit's whole
  history (commits, trees, blobs) is present after storing the pack, else `ng <b> missing`;
  (3) `new` is a descendant of `old` (or old is zeros), else `ng <b> non-fast-forward`;
  (4) the branch name is valid (no "..", no leading or trailing "/", no control chars or spaces,
  1 to 200 bytes), else `ng <b> bad-name`. Objects from a rejected push may stay stored; refs never move.
- A malformed pack or request body -> 400 and no change. Packs over 64 MiB or 100 000 objects -> 413.
- The client is a small HTTP/1.1 client over `TcpStream` using mercury's `write_request` and
  `parse_response` (Content-Length bodies, `Connection: close`). Non-200 -> `Err(Http(status))`.
- Fetch sends as haves the commits it already has that are tips of its branches (and their
  ancestors are implied); the server must not resend objects reachable from them.

## Tests required
- Pack round trip (`forall` 300 cases) and corrupted packs (bit flip, truncation, wrong count,
  huge length fields) giving `Err`, never panic.
- Live server tests on 127.0.0.1: clone, commit on both sides, pull (true merge), push; push
  rejected as stale and non-fast-forward with the server ref unchanged; push of a new branch;
  bad branch name; fetch with haves returns only new objects (count them in the pack).

## Extra check the leader will run
Two and three clones changing both sides and syncing to an identical file state; 8 threads
pushing to the same branch at once (exactly the winners advance it, history stays linear, every
loser gets `stale` or `non-fast-forward`); forged packs and missing objects rejected with refs
unchanged; fetch minimality by object counts; fuzzed request bodies never crash the server.

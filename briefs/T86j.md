## Tool
- `iris`: `replay EVENTS --out FRAME.png [--width W --height H]`: EVENTS lines open/close/move/focus/tile/key in a simple text format you document in `--help`, applied to a `Desktop`; writes the final composited frame (pigment for PNG) and prints window list and damage stats.

## Tests
`tests/cli_iris.rs` as `docs/APPS.md` says: `--help`, `--version`, every subcommand on a good input, one bad input
each (exit 1 and a `iris:` message), an unknown subcommand (exit 2). Run `cargo fmt -p iris` before the gate.

## Report

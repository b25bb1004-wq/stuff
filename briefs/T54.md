## Public API (exact, re-exported from the crate root)
```rust
/// Text as a piece table over an immutable original and an append-only add buffer.
/// All positions are byte offsets into the UTF-8 text and must lie on char boundaries.
pub struct Buffer { /* ... */ }
impl Buffer {
    pub fn new(text: &str) -> Buffer;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    pub fn text(&self) -> alloc::string::String;
    pub fn slice(&self, start: usize, end: usize) -> alloc::string::String; // panics if out of range
    pub fn insert(&mut self, at: usize, s: &str);       // panics if `at` is out of range or not a boundary
    pub fn delete(&mut self, start: usize, end: usize); // same rules
    pub fn line_count(&self) -> usize;                  // number of '\n' plus 1
    pub fn line_start(&self, line: usize) -> Option<usize>; // byte offset where line `line` (0-based) starts
    pub fn line_of(&self, at: usize) -> usize;          // line containing byte `at` (at == len allowed)
    pub fn pieces(&self) -> usize;                      // piece count, for tests: stays O(edits), merges adjacent typing
}
/// Undo tree: every edit is a node; undo after a new edit keeps the old branch reachable.
pub struct Editor { pub buffer: Buffer, /* history, cursors */ }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Cursor { pub anchor: usize, pub head: usize } // selection = min..max; empty when equal
impl Editor {
    pub fn new(text: &str) -> Editor;              // one cursor at 0
    pub fn cursors(&self) -> &[Cursor];            // sorted by min, never overlapping (merged)
    pub fn set_cursors(&mut self, c: alloc::vec::Vec<Cursor>); // sorts and merges overlapping/touching selections
    /// Replace every selection (or insert at every empty cursor) with `s`, as ONE undo step;
    /// afterwards each cursor is empty and sits just after its inserted text.
    pub fn type_text(&mut self, s: &str);
    /// Delete each selection, or for an empty cursor the char before it (backspace), as ONE undo step.
    pub fn backspace(&mut self);
    pub fn undo(&mut self) -> bool;                // false at the root
    pub fn redo(&mut self) -> bool;                // goes down the most recent child branch
    pub fn branches(&self) -> usize;               // children of the current node
    pub fn redo_branch(&mut self, i: usize) -> bool; // go down child i (0 = oldest)
}
/// Regex: compile once, run in guaranteed linear time (Thompson NFA / Pike VM, no backtracking).
pub struct Regex { /* ... */ }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RegexError { pub pos: usize, pub msg: &'static str }
impl Regex {
    pub fn new(pattern: &str) -> Result<Regex, RegexError>;
    /// Leftmost match starting at or after `start`, with Python `re` semantics for which match
    /// wins (leftmost, then the preference order of alternation and greedy/lazy repetition).
    /// Returns byte ranges of the whole match and of each capture group (None if it did not take part).
    pub fn find_at(&self, text: &str, start: usize) -> Option<alloc::vec::Vec<Option<(usize, usize)>>>;
    pub fn is_match(&self, text: &str) -> bool;
    pub fn find_iter(&self, text: &str) -> alloc::vec::Vec<(usize, usize)>; // like re.finditer spans
}
```
## Regex syntax (the subset of Python `re` to support, exactly as Python interprets it)
Literals and escapes `\\ \. \* \+ \? \( \) \[ \] \{ \} \| \^ \$ \/ \- \n \t`, `.` (not newline),
classes `[abc] [^a-z] [a\-z] []a]`, `\d \w \s \D \W \S` (ASCII meanings, as Python with
`re.ASCII`), anchors `^ $` (no MULTILINE: `$` also matches before a final `\n`, as in Python), `\b \B`,
groups `( )`, non-capturing `(?: )`, alternation `|`, quantifiers `* + ? {n} {n,} {n,m} {,m}` and
lazy forms `*? +? ?? {n,m}?`. Errors (RegexError) for: unbalanced parentheses or brackets, nothing
to repeat, `{m,n}` with m > n, a bad escape, and repetition counts above 1000. Matching works on
chars (a `.` matches one whole UTF-8 char). `find_iter` follows Python: after an empty match at p,
the next search retries at p refusing only an empty match there, and an empty match right after a previous match is allowed
(Python 3.7+ rules).

  the original text.

  semantics, error cases, and a pathological case (`(a*)*b` on 30 000 `a`) finishing in under
  a second.

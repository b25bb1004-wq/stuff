## Public API (exact, re-exported from the crate root)
```rust
pub const GLYPH_W: u32 = 8;
pub const GLYPH_H: u32 = 16;
/// 16 rows of 8 bits (bit 7 = leftmost pixel) for the glyph drawn for `ch`.
/// ASCII 0x20..=0x7E have their own glyphs; every other char gets the replacement glyph
/// (a hollow box), which differs from all ASCII glyphs.
pub fn glyph(ch: char) -> [u8; 16];
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Line { pub start: usize, pub end: usize, pub width: u32 } // byte range into the text
pub fn measure(text: &str, scale: u32) -> (u32, u32);    // (width, height) of `layout(text, u32::MAX, scale)`
pub fn layout(text: &str, max_width: u32, scale: u32) -> alloc::vec::Vec<Line>;
impl Canvas {
    pub fn draw_text(&mut self, x: i32, y: i32, text: &str, c: Rgba, scale: u32, max_width: u32) -> (u32, u32);
    // draws `layout(text, max_width, scale)`, line i at y + i*GLYPH_H*scale; returns the size drawn
}
```
## Behaviour
- Monospace cell `GLYPH_W*scale` by `GLYPH_H*scale` (scale 0 is treated as 1). Each set font bit
  becomes a `scale`x`scale` block blended with `c` (no anti-aliasing). Glyphs keep a baseline at
  row 12 and leave column 7 empty, so adjacent letters never touch.
- Layout: `\n` ends a line (not part of either line); `\r\n` counts as one break; a tab advances
  to the next multiple of 4 cells. Wrap at spaces: a line never gets wider than `max_width`
  unless a single character is wider than `max_width` (then one character per line). The spaces
  where a line wraps belong to no line; a word longer than `max_width` is broken between
  characters. Width counts chars (not bytes). Empty text is one empty line; trailing `\n` adds
  an empty last line.
- Lines are byte ranges on char boundaries, in order, never overlapping, and together with the
  dropped break characters cover the whole text.
- Never panic: any text, any width (0 included), any scale up to 64, any position.

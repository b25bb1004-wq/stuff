## Goal
Everything the public sees comes from one small image: the site at `/`, Athena at `/athena/`, a health route.
Iridium, the registry and Aurum stay private (no auth): never published on a public interface by default.

## Design (fixed by the leader)
- `src/web.rs`: `pub fn run_web(listen: &str, root: &Path, stop: &AtomicBool) -> io::Result<()>` using mercury
  `Router`: exact `GET /healthz` returns `200 ok` (text/plain); `static_dir("/", root)` serves the bundle
  (`index.html` for directories, `/athena/` included). Refuse to start if `root/index.html` or
  `root/athena/index.html` is missing (clear error). Same stop/poll pattern as `run_registry`.
- `src/bin/monolith-web.rs`: `monolith-web --listen ADDR --root DIR` (defaults `0.0.0.0:8080`, `/www`), SIGTERM via
  the existing `shutdown` module, exits 0 within 2 s.
- Docker: new stage `web-bundle` FROM the build stage that runs `rustup target add wasm32-unknown-unknown
  riscv64gc-unknown-none-elf` and `cargo run --release --locked -p site --example pack` (it writes
  `target/site-web` with `athena/` inside); final stage `web` FROM scratch with `/monolith-web`, `/healthcheck`,
  `/www` (the bundle), USER 65534, EXPOSE 8080, HEALTHCHECK `http 127.0.0.1:8080 /healthz`. Existing stages unchanged.
- `compose.yaml`: service `web` (ports `"8080:8080"`, the only service on all interfaces), `read_only: true`,
  healthcheck. Other services keep `127.0.0.1` ports.
- `README.md`, new section "Public hosting" (at most 25 lines): the `web` image is the only thing to expose;
  mercury has no TLS, so put Caddy, nginx or the platform's HTTPS in front (needed for Athena's install button,
  service workers need HTTPS); add security headers there (`X-Content-Type-Options: nosniff`, a CSP of
  `default-src 'self'; script-src 'self' 'wasm-unsafe-eval'`); `target/site-web` is also a plain static folder
  any static host can serve; never expose 7400, 7500, 7601-7603 or 7700.

## Tests
- `tests/web.rs`: build a temp root with `index.html`, `athena/index.html`, `site.wasm` (a few bytes); start
  `run_web` on `127.0.0.1:0`-style free port in a thread; with plain `TcpStream` requests check: `/healthz` 200 `ok`;
  `/` 200 with the index body and `text/html`; `/athena/` 200; `/site.wasm` has `Content-Type: application/wasm`;
  `/../Cargo.toml` and `/%2e%2e/x` give 403 or 404, never file contents; a missing file 404; stop flag ends the server
  within 2 s. Missing `athena/index.html` makes `run_web` return an error.
- `tests/docker_files.rs`: parse `docker/Dockerfile` and `compose.yaml` as text: stage `web` exists FROM scratch with
  USER 65534 and HEALTHCHECK; compose `web` publishes 8080 and every other published port starts with `127.0.0.1:`.

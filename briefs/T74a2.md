## Design (fixed by the leader)
- `Compiled` gets `pub debug: Debug` with, per function, `name: String` and `locals: Vec<LocalVar { reg: u32,
  name: String, from_pc: u32, to_pc: u32 }>` (the op range where that Logos binding is live; params from 0).
  Existing `spans` give pc to line. Helpers in `debug.rs`: `line_of(c, func, pc) -> Option<(u32, u32)>`,
  `first_pc_of_line(c, line) -> Vec<(u32, u32)>` (func, pc) for breakpoints, `locals_at(c, func, pc) ->
  Vec<(String, u32)>`.
- `pub fn step(c, session, vm, host, mode: Step, breakpoints: &[u32]) -> Event` with `Step::{Continue, Over, Into,
  Out}`: Continue pauses at any breakpoint line; Into pauses when the source line changes at any depth; Over when it
  changes at the same or a smaller depth; Out when depth drops below the start depth. All also pause at
  breakpoints. Bound each call (default 5 M ops, then `Budget`).

## Tests
`tests/debug.rs`: a Logos program with `main` calling `add`; a breakpoint on the `add` body line pauses there with
locals `a`, `b` at the call's values; Over on a call line does not stop inside `add`; Into does; Out returns to
`main`; a loop with a breakpoint pauses once per iteration; `line_of` matches the spans; an endless loop with
Continue returns `Budget`.

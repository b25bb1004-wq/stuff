# T06 shale: file system core (format, mkfs, read and write paths)
Worker: haiku, medium. Budget: 170k tokens. First read `briefs/_RULES.md`.

**May touch:** `crates/shale/**` only. `#![forbid(unsafe_code)]` stays.
The crate is `#![cfg_attr(not(test), no_std)]` with `extern crate alloc;`.
Shale is the file system of Strata OS. This task builds everything except the journal (T07).

## On-disk format, version 1 (all integers little endian)
- Block size 4096 (`BLOCK`). Block 0: superblock. Then the journal area (reserved, 64 blocks by
  default, all zero for now), the block bitmap (1 bit per block of the whole device), the inode
  table, then data blocks.
- Superblock: magic `SHALE001`, block count, inode count, start and length of journal, bitmap,
  inode table, first data block, root inode number (1), and a CRC-32C of the bytes before it.
- Inode: 128 bytes, 32 per block. Fields: kind (0 free, 1 file, 2 directory), link count, size
  in bytes, 6 direct extents (start block u32, length u32), one indirect block number (a block
  holding up to 511 more extents plus a CRC-32C), and a CRC-32C of the inode. Inode 0 is never
  used; inode 1 is the root directory.
- Directory: a file whose content is packed entries `[inode u32][name_len u8][name bytes]`.
  A removed entry has inode 0 and keeps its length so the scan can skip it. Names are 1 to 255
  bytes, any byte except `/` and 0. `.` and `..` are not stored; paths are resolved from the root.
- CRC-32C (Castagnoli, polynomial 0x1EDC6F41 reflected) is implemented in this crate, table
  driven. Test value: CRC-32C of the nine ASCII bytes 123456789 is `0xE3069283`.

## Public API (exact)
```rust
pub const BLOCK: usize = 4096;
pub enum Error { Io, Corrupt, NotFound, Exists, NotDir, IsDir, NotEmpty, NoSpace, NameTooLong,
                 BadPath, TooLarge }                       // Debug, Clone, Copy, PartialEq, Eq
pub trait BlockDevice {
    fn block_count(&self) -> u64;
    fn read(&mut self, block: u64, buf: &mut [u8; BLOCK]) -> Result<(), Error>;
    fn write(&mut self, block: u64, buf: &[u8; BLOCK]) -> Result<(), Error>;
    fn flush(&mut self) -> Result<(), Error>;
}
pub struct MemDisk;        // new(blocks: u64); impl BlockDevice; bytes(&self) -> &[u8]; bytes_mut(&mut self) -> &mut [u8]
pub struct MkfsOptions { pub inodes: u32, pub journal_blocks: u32 }   // impl Default: inodes = blocks / 4 (min 32), journal 64
pub fn mkfs<D: BlockDevice>(dev: &mut D, opts: MkfsOptions) -> Result<(), Error>;   // NoSpace if the device is too small
pub enum Kind { File, Dir }
pub struct Stat { pub kind: Kind, pub size: u64, pub inode: u32, pub links: u32 }
pub struct DirEntry { pub name: alloc::string::String, pub kind: Kind, pub inode: u32 }
pub struct FsStat { pub total_blocks: u64, pub free_blocks: u64, pub free_inodes: u32 }
pub struct Fs<D: BlockDevice>;
impl<D: BlockDevice> Fs<D> {
    pub fn mount(dev: D) -> Result<Fs<D>, Error>;          // Corrupt on bad magic, CRC or layout
    pub fn unmount(self) -> Result<D, Error>;              // flushes
    pub fn create(&mut self, path: &str) -> Result<(), Error>;          // empty file; Exists if present
    pub fn mkdir(&mut self, path: &str) -> Result<(), Error>;
    pub fn write(&mut self, path: &str, offset: u64, data: &[u8]) -> Result<usize, Error>; // grows the file; a gap reads as zeros
    pub fn read(&mut self, path: &str, offset: u64, buf: &mut [u8]) -> Result<usize, Error>; // short read at end of file
    pub fn truncate(&mut self, path: &str, size: u64) -> Result<(), Error>;  // shrink frees blocks; grow zero-fills
    pub fn remove(&mut self, path: &str) -> Result<(), Error>;          // files only; IsDir for a directory
    pub fn rmdir(&mut self, path: &str) -> Result<(), Error>;           // NotEmpty unless empty; BadPath for the root
    pub fn rename(&mut self, from: &str, to: &str) -> Result<(), Error>; // Exists if `to` exists; a directory may not move into itself (BadPath)
    pub fn list(&mut self, path: &str) -> Result<alloc::vec::Vec<DirEntry>, Error>;  // sorted by name
    pub fn stat(&mut self, path: &str) -> Result<Stat, Error>;
    pub fn statfs(&mut self) -> Result<FsStat, Error>;
}
```
Paths are absolute and `/` separated, for example `/a/b.txt`; `/` alone is the root. Empty
components and relative paths are `BadPath`; a name over 255 bytes is `NameTooLong`.
Maximum file size is what 6 + 511 extents can map; beyond it `TooLarge`. Extents should merge
when a file grows into the next free block.

**Design rule for T07:** every operation collects the blocks it changes in one private
`Txn` (a map from block number to a 4096-byte copy) and writes them in a single `commit` at the
end. No operation writes to the device anywhere else. Reads inside the operation see the dirty
copies. If an operation fails half way, it drops the `Txn` and the disk is unchanged.

## Tests required
- CRC-32C test value; mkfs then mount on devices of 64, 256 and 4096 blocks (use a smaller
  journal for the 64-block one); a device that is too small fails with `NoSpace`.
- Shadow-model property test (`forall`, at least 100 cases of 300 operations): random create,
  mkdir, write (sizes 0 to 20 000, random offsets), read, truncate, remove, rmdir, rename, list,
  stat on a small name pool, against an in-memory model (a map of path to bytes and a set of
  directories). Every result, error kind and byte must match. Every 50 operations unmount,
  mount again and compare the whole tree with the model.
- Space accounting: fill the disk until `NoSpace`, remove everything, `statfs` must equal its
  value right after mkfs. A failed operation changes nothing (compare `MemDisk::bytes` before
  and after).
- Corruption: flip random bytes in the superblock, the bitmap, the inode table and directory
  blocks of a populated image, then mount and run every operation: each call returns `Ok` or
  `Err`, never panics, never loops forever (`forall`, at least 300 cases). Mount of pure random
  bytes fails with `Corrupt`.

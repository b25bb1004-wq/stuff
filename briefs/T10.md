## Public API (exact; Sinter (T18, T29) and the IR interpreter (T19) are written against it)
```rust
pub mod check { pub fn check(m: &ast::Module) -> Result<ir::Program, Diag>; }   // first error wins
pub mod ir {
    pub type Reg = u32;  pub type Label = u32;  pub type FuncId = u32;  pub type TypeId = u32;
    pub enum Ty { Int, Byte, Bool, Str, Unit, Array(Box<Ty>), Tuple(Vec<Ty>), Opt(Box<Ty>),
                  Named(TypeId), Fn { params: Vec<Ty>, ret: Box<Ty>, layers: u64 } }
    pub enum TypeKind { Record(Vec<(String, Ty)>), Variants(Vec<(String, Vec<Ty>)>) }
    pub struct TypeInfo { pub name: String, pub kind: TypeKind }
    pub enum Lit { Int(i64), Byte(u8), Bool(bool), Unit, Str(String), Fn(FuncId) }
    pub enum Builtin { Len, Push, Pop, Slice, Concat, IntToStr, ParseInt, Bytes, Text, ToInt,
                       ToByte, Min, Max, Abs }
    pub enum Inst {
        Lit(Reg, Lit), Move(Reg, Reg),
        Un(Reg, ast::UnOp, Reg), Bin(Reg, ast::BinOp, Reg, Reg),    // never And/Or: lowered to branches
        Call(Reg, FuncId, Vec<Reg>), CallValue(Reg, Reg, Vec<Reg>), Builtin(Reg, Builtin, Vec<Reg>),
        NewArray(Reg, Vec<Reg>), NewFill(Reg, Reg, Reg), NewTuple(Reg, Vec<Reg>),
        NewRecord(Reg, TypeId, Vec<Reg>), NewVariant(Reg, TypeId, u32, Vec<Reg>),
        NewSome(Reg, Reg), NewNone(Reg),
        GetField(Reg, Reg, u32), SetField(Reg, u32, Reg), Tag(Reg, Reg),
        GetIndex(Reg, Reg, Reg), SetIndex(Reg, Reg, Reg),
        Label(Label), Jump(Label), Branch(Reg, Label, Label),       // Branch(cond, if_true, if_false)
        Ret(Reg), Assert(Reg, String),
    }
    pub enum Body { Code { insts: Vec<Inst>, spans: Vec<Span> }, Extern(String) }  // spans[i] is the source of insts[i]
    pub struct Func { pub name: String, pub params: u32, pub ret: Ty, pub layers: u64,
                      pub regs: Vec<Ty>, pub body: Body }            // regs[0..params] are the parameters
    pub struct Prop { pub name: String, pub func: FuncId, pub guard: Option<FuncId> }  // guard: same params -> bool
    pub struct Program { pub types: Vec<TypeInfo>, pub layers: Vec<String>, pub funcs: Vec<Func>,
                         pub tests: Vec<(String, FuncId)>, pub props: Vec<Prop>, pub main: Option<FuncId> }
}
```
All IR types derive `Debug, Clone, PartialEq`. Layer bits: `io fs net time rand chain sys` are bits
0..=6 in that order, declared layers follow in declaration order; more than 64 is a `Diag`.
`Program::layers` lists the names by bit.

## Behaviour
- Every rule in `docs/MICA.md` sections Types, Layers and Semantics that a compiler can check:
  name resolution (values, types, variants, layers; duplicates), no implicit conversions, inferred
  `let`/`var` types, `[]` and `none` need a known type, `==` only on the listed types, `match`
  exhaustive, places only for `var` names, fields and indexes, `break`/`continue` only in loops,
  `return` type, block values, `if`/`match` branch types, `for` over a range or an array, ranges
  only in `for` and slices, function values only from named functions, `const` initialisers are
  literals or constant arithmetic (fold them; overflow in a constant is a `Diag`), `main` has no
  parameters, `prop` bodies and guards have an empty layer set.
- Layer errors name the full call path, exactly: `layer 'net' is not allowed here: main -> sync -> fetch (uses net)`.
- Built-in functions are resolved by name unless a user function has that name (then a `Diag`).
- Lowering: pipes become calls, `&&`/`||` become branches (short-circuit), `if`/`match`/blocks
  write a result register, `match` uses `Tag`/`GetField` and literal compares, `for` over an array
  re-reads the length each step, `==`/`!=` on tuples and options become element compares, so `Bin`
  `Eq`/`Ne` only ever sees `Int Byte Bool Unit Str`. Left-to-right evaluation is kept.
- Every `Code` body ends in `Ret` or `Jump`; every `Label` used is defined once; every register
  has a type. Write a private `validate(&Program)` that checks this and run it in tests.

## Tests required
- `tests/typed/*.mica`: at least 20 programs that must check (use the T09 corpus where valid),
  each run through `validate`.
- `tests/reject/*.mica`: at least one program per rule above (40 or more), each starting with a
  line `// error: <message start>`; the test asserts the `Diag` message starts with that text and
  the span lies inside the file.
- Fuzz (`forall`, 2000 cases): T09 corpus programs with random edits, and random token soups that
  happen to parse: `check` returns `Ok` (then `validate` passes) or `Err`, never panics.

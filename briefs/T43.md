## Why
Version control for Strata. Object ids are byte-for-byte git's SHA-256 object format, so any
object Drillcore writes has the same id git gives it (`git init --object-format=sha256`). Diff
and merge (T44) and push/pull over HTTP (T45) build on this.

## Public API (exact)
```rust
pub type Id = [u8; 32];
pub fn to_hex(id: &Id) -> String;
pub fn from_hex(s: &str) -> Option<Id>;
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Kind { Blob, Tree, Commit }
pub fn hash_object(kind: Kind, data: &[u8]) -> Id;   // sha256("blob 12\0" ++ data), like git
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)] pub enum Mode { File, Exec, Dir } // 100644 100755 40000
#[derive(Debug, Clone, PartialEq, Eq)] pub struct TreeEntry { pub mode: Mode, pub name: String, pub id: Id }
pub fn encode_tree(entries: &[TreeEntry]) -> Vec<u8>;            // sorts in git order itself
pub fn decode_tree(data: &[u8]) -> Result<Vec<TreeEntry>, Error>;
#[derive(Debug, Clone, PartialEq, Eq)] pub struct Signature { pub name: String, pub email: String, pub time: i64, pub tz_minutes: i32 }
#[derive(Debug, Clone, PartialEq, Eq)] pub struct Commit { pub tree: Id, pub parents: Vec<Id>, pub author: Signature, pub committer: Signature, pub message: String }
pub fn encode_commit(c: &Commit) -> Vec<u8>;
pub fn decode_commit(data: &[u8]) -> Result<Commit, Error>;
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Error { NotFound, Corrupt, BadName, Exists, NoCommits, Dirty }
pub trait Store {                                    // a flat key-value namespace of paths
    fn read(&self, path: &str) -> Option<Vec<u8>>;
    fn write(&mut self, path: &str, data: &[u8]);
    fn remove(&mut self, path: &str);
    fn list(&self, prefix: &str) -> Vec<String>;     // full paths starting with prefix, sorted
}
#[derive(Default)] pub struct MemStore { /* BTreeMap */ }
#[cfg(feature = "std")] pub struct DirStore { /* root PathBuf */ }  // DirStore::new(root)
pub type Files = alloc::collections::BTreeMap<String, (Vec<u8>, bool)>; // path -> (bytes, executable)
pub struct Repo<S: Store> { pub store: S }
impl<S: Store> Repo<S> {
    pub fn init(store: S) -> Repo<S>;                 // HEAD -> refs/heads/main, no commits
    pub fn open(store: S) -> Result<Repo<S>, Error>;  // Corrupt if HEAD is missing
    pub fn put(&mut self, kind: Kind, data: &[u8]) -> Id;
    pub fn get(&self, id: &Id) -> Result<(Kind, Vec<u8>), Error>; // re-hashes; Corrupt on mismatch
    pub fn add(&mut self, path: &str, data: &[u8], exec: bool) -> Result<(), Error>; // stage
    pub fn rm(&mut self, path: &str) -> Result<(), Error>;          // unstage + delete; NotFound
    pub fn staged(&self) -> Files;                                  // what the next commit holds
    pub fn commit(&mut self, message: &str, who: &Signature) -> Result<Id, Error>; // author = committer
    pub fn head(&self) -> Option<Id>;
    pub fn current_branch(&self) -> Option<String>;  // None when HEAD is detached
    pub fn branches(&self) -> Vec<(String, Id)>;
    pub fn branch(&mut self, name: &str, at: &Id) -> Result<(), Error>;   // Exists, BadName
    pub fn delete_branch(&mut self, name: &str) -> Result<(), Error>;     // not the current one
    pub fn checkout(&mut self, rev: &str) -> Result<Files, Error>;        // branch name or any rev
    pub fn resolve(&self, rev: &str) -> Option<Id>;  // HEAD, branch, full hex, unique hex prefix >= 4, X~n, X^
    pub fn log(&self, from: &Id) -> Result<Vec<Id>, Error>;   // all reachable, newest committer time first, ties by id
    pub fn files(&self, commit: &Id) -> Result<Files, Error>;
}
```
## Behaviour
- Formats exactly git's: tree entry `"<mode> <name>\0" ++ 32 raw id bytes`, modes as octal text
  without leading zero (`40000` for trees); entries sorted by name bytes with directory names
  compared as if they ended in `/`. Commit text: `tree <hex>\n`, one `parent <hex>\n` per
  parent, `author <name> <<email>> <time> <+hhmm|-hhmm>\n`, same for `committer`, `\n`, message
  stored as given. Empty directories do not exist; nested paths make nested trees.
- Store layout (our own, uncompressed): `objects/<2 hex>/<62 hex>` holds `"<kind> <len>\0" ++ data`;
  `refs/heads/<name>` holds hex + `\n`; `HEAD` holds `ref: refs/heads/<name>\n` or a hex id;
  `index` is your own format holding path, mode and blob id (the blob is written at `add`).
- Paths: `/`-separated, no empty, `.` or `..` component, no NUL, no leading `/`: else `BadName`.
  Branch names: `[A-Za-z0-9._/-]`, not starting with `-` or `.`, no `..`, no trailing `/` or `.lock`.
- `commit` with an index equal to HEAD's tree still commits (git `--allow-empty`); the first
  commit has no parent; `checkout` refuses with `Dirty` when the index differs from HEAD's tree,
  otherwise sets HEAD (symbolic for a branch name, detached otherwise), sets the index to that
  tree and returns its files.
- Never panic on corrupt store contents; return `Corrupt`.

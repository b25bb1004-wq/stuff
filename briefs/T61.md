## Public API (crate root, exact)
```rust

#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Dir { Row, Column }

#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Align { Start, Center, End, Stretch }
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]

#[derive(Debug, Clone, Copy, PartialEq, Eq)]

    pub grow: u32, pub width: Option<u32>, pub height: Option<u32>, pub min_w: u32, pub min_h: u32 }
impl Default for Style  // Column, Start, Stretch, gap 0, no padding, grow 0, None, None, 0, 0

#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Key { Tab, ShiftTab, Enter, Space, Backspace, Escape }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Event { MouseMove { x: i32, y: i32 }, MouseDown { x: i32, y: i32 }, MouseUp { x: i32, y: i32 }, Key(Key), Text(char) }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Action { Clicked(NodeId), Changed(NodeId), Submitted(NodeId), Focused(Option<NodeId>) }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Theme { pub bg: Rgba, pub fg: Rgba, pub button: Rgba, pub button_hover: Rgba,
    pub button_pressed: Rgba, pub field_bg: Rgba, pub focus_ring: Rgba, pub text_scale: u32 }
impl Theme { pub fn light() -> Theme; pub fn dark() -> Theme; } // all colours opaque, scale 1 or more
pub struct Ui;
impl Ui {

    pub fn root(&self) -> NodeId;
    pub fn add(&mut self, parent: NodeId, kind: Kind, style: Style) -> Option<NodeId>; // None unless parent is a live Box
    pub fn remove(&mut self, id: NodeId) -> bool;   // removes the subtree; the root cannot be removed
    pub fn children(&self, id: NodeId) -> &[NodeId]; // empty for unknown ids
    pub fn text(&self, id: NodeId) -> Option<&str>;
    pub fn set_text(&mut self, id: NodeId, text: &str) -> bool;
    pub fn layout(&mut self, width: u32, height: u32);
    pub fn rect(&self, id: NodeId) -> Option<Rect>; // from the last layout
    pub fn hit(&self, x: i32, y: i32) -> Option<NodeId>;
    pub fn focus(&self) -> Option<NodeId>;
    pub fn event(&mut self, ev: Event) -> Vec<Action>;
    pub fn render(&self, canvas: &mut Canvas);
}
```

## Layout (exact; the leader's model follows these words)
- **Content size.** Label and Button: `pigment::text::measure(text, theme.text_scale)`. Field:
  `(max(measure.w, 80 * scale), 16 * scale)`. Box: along its main axis the sum of the children's
  base main sizes plus `gap * (n - 1)`; across, the largest child base cross size (0, 0 if empty).
- **Base size** of a node: `width.unwrap_or(content_w + left + right)`, same for height with top
  and bottom, then at least `min_w`/`min_h`. Main axis of a Row is x, of a Column is y.
- `layout(w, h)` gives the root the rect `(0, 0, w, h)`. A Box with rect R places its children in
  the inner rect (R minus padding, saturating at 0). Let `free = inner_main - sum(base main) -
  gap * (n - 1)` (signed). If `free > 0` and the total grow `G > 0`: child i gets
  `floor(free * grow_i / G)` extra, then the left-over pixels go one each to the growing children
  in child order. Justify applies only when nothing grew: Start 0, End `free`, Center
  `floor(free / 2)` before the first child; SpaceBetween adds `floor(free / (n - 1))` to every
  gap (one child: Start). When `free <= 0` children keep their base size and overflow.
- **Cross axis.** Stretch: the child's cross size is the inner cross size, unless the child sets
  its own cross size (`height` in a Row, `width` in a Column), then it is placed as Start.
  Start, Center (`floor`), End place the base cross size inside the inner cross size (a child
  larger than the space starts at the inner edge and overflows).
- Positions are i32; sizes u32; use saturating arithmetic. Leaves have no children.

## Events and focus
- `hit`: the deepest live node whose rect contains the point (`x <= px < x + w`, same for y);
  later siblings are on top. Outside the root: None.
- Focusable widgets: Button and Field. Tab moves focus to the next focusable in pre-order
  (children in order), wrapping; from no focus it goes to the first. ShiftTab goes backwards; from
  no focus to the last. Each change emits `Focused(new)`. Escape clears focus (`Focused(None)` if
  it was set). No focusable widget: Tab and ShiftTab do nothing.
- MouseDown on a Button presses it and focuses it; MouseUp on the same pressed Button emits
  `Clicked`; any MouseUp releases. MouseDown on a Field focuses it. MouseDown on anything else
  clears focus. Focus changes from the mouse also emit `Focused`.
- Enter or Space on a focused Button: `Clicked`. On a focused Field: `Text(c)` appends `c` and
  emits `Changed`; Backspace removes the last char and emits `Changed` (nothing if empty); Enter
  emits `Submitted`. MouseMove sets the hovered Button (render only). Removing the focused,
  pressed or hovered node clears that state silently.
- Actions come out in the order they happen (`Focused` before `Clicked` for one MouseUp).

## Render (the leader checks these pixels)
Fill the canvas with `bg`. Button: fill its rect with `button_pressed` if pressed, else
`button_hover` if hovered, else `button`. Field: fill with `field_bg`. Then draw each Label,
Button and Field text in `fg` at `(rect.x + padding.left, rect.y + padding.top)` with
`max_width` = inner width. The focused widget gets `stroke_rect(rect, focus_ring)` last. Children
paint after parents, in child order.

## Public API (crate root, exact)
```rust
pub type Hash = [u8; 32];
pub type Address = [u8; 32];          // an ed25519 public key
pub const MAX_DATA: usize = 1024;     // bytes of Tx::data
pub const MAX_TXS: usize = 1000;      // transactions per block
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Tx { pub from: Address, pub to: Address, pub amount: u64, pub fee: u64, pub nonce: u64,
    pub data: Vec<u8>, pub sig: [u8; 64] }
impl Tx {
    pub fn signed(seed: &[u8; 32], to: Address, amount: u64, fee: u64, nonce: u64, data: Vec<u8>) -> Tx;
    pub fn body(&self) -> Vec<u8>;
    pub fn encode(&self) -> Vec<u8>;
    pub fn decode(bytes: &[u8]) -> Result<Tx, DecodeError>;
    pub fn id(&self) -> Hash;
    pub fn verify(&self) -> bool;
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Header { pub height: u64, pub parent: Hash, pub tx_root: Hash, pub state_root: Hash,
    pub time: u64, pub proposer: Address, pub sig: [u8; 64] }
impl Header {
    pub fn encode(&self) -> Vec<u8>;          // always 208 bytes
    pub fn hash(&self) -> Hash;
    pub fn sign(&mut self, seed: &[u8; 32]);  // sets sig only; proposer is not touched
    pub fn verify(&self) -> bool;
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Block { pub header: Header, pub txs: Vec<Tx> }
impl Block {
    pub fn encode(&self) -> Vec<u8>;
    pub fn decode(bytes: &[u8]) -> Result<Block, DecodeError>;
    pub fn hash(&self) -> Hash;               // header.hash()
}
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DecodeError { Truncated, TrailingBytes, TooLarge }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TxError { TooLarge, BadSignature, BadNonce, InsufficientFunds, Overflow }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum BlockError { BadHeight, BadParent, BadTime, WrongProposer, BadSignature, TooLarge,
    BadTxRoot, BadTx { index: usize, error: TxError }, BadStateRoot }
pub fn merkle_root(leaves: &[Vec<u8>]) -> Hash;
pub fn merkle_proof(leaves: &[Vec<u8>], index: usize) -> Vec<Hash>;
pub fn merkle_verify(root: &Hash, leaf: &[u8], index: usize, count: usize, proof: &[Hash]) -> bool;
#[derive(Debug, Clone)]
pub struct Chain;
impl Chain {
    pub fn new(genesis: &[(Address, u64)], validators: &[Address]) -> Chain; // validators non-empty
    pub fn genesis(&self) -> &Block;
    pub fn tip(&self) -> &Header;
    pub fn height(&self) -> u64;
    pub fn block(&self, height: u64) -> Option<&Block>;
    pub fn account(&self, address: &Address) -> (u64, u64);   // (balance, nonce), (0, 0) if unknown
    pub fn state_root(&self) -> Hash;
    pub fn expected_proposer(&self) -> Address;
    pub fn propose(&self, seed: &[u8; 32], time: u64, txs: Vec<Tx>) -> Result<Block, BlockError>;
    pub fn append(&mut self, block: Block) -> Result<(), BlockError>;
}
```

## Encodings (all integers little-endian)
- `Tx::body` = `from(32) to(32) amount(8) fee(8) nonce(8) len(u32) data`. `encode` = `body || sig`.
  `sig` = `sphinx::ed25519::sign(seed, b"aurum-tx\0" || body)`; `verify` checks it against `from`.
  `id` = `sha256(encode)`. `Tx::signed` sets `from = sphinx::ed25519::public_key(seed)`.
- `Header::encode` = `height(8) parent(32) tx_root(32) state_root(32) time(8) proposer(32) sig(64)`.
  The signed message is `b"aurum-blk" || encode[..144]`; `verify` checks `sig` against `proposer`.
  `hash` = `sha256(encode)` (all 208 bytes).
- `Block::encode` = `header(208) count(u32) tx encodings back to back`.
- Decoding reads fields in order: running out of bytes is `Truncated`; a data length above
  `MAX_DATA` is `TooLarge` as soon as the length is read; a block count above `MAX_TXS` is
  `TooLarge` as soon as the count is read; bytes left after the last field are `TrailingBytes`.
  `decode(encode(x)) == Ok(x)`. Hostile bytes never panic.

## Merkle tree (RFC 6962 / RFC 9162)
Leaf hash `sha256(0x00 || leaf)`, node hash `sha256(0x01 || left || right)`, empty tree
`sha256("")`. For n > 1 leaves split at k = the largest power of two below n: root =
node(root(first k), root(rest)). `merkle_proof` is the RFC 6962 audit path (deepest sibling
first); an index outside the leaves gives an empty proof. `merkle_verify` is the RFC 9162 section
2.1.3.2 algorithm (false for `index >= count`, wrong proof length, or any mismatch).

## State
Accounts map address to (balance, nonce). The state root is `merkle_root` over the 48-byte
leaves `address || balance(8) || nonce(8)` of every account not equal to (0, 0), sorted by address.
Genesis: balances of the list (a repeated address adds up), nonces 0.

## Chain
- Genesis block: height 0, parent zeros, `tx_root = merkle_root(&[])`, `state_root` of genesis,
  time 0, proposer zeros, sig zeros, no txs. It is never signature-checked.
- `expected_proposer` = `validators[(height() + 1) % validators.len()]`.
- Applying a tx with block proposer `p`, checks in this order: `data.len() > MAX_DATA` TooLarge;
  `!verify()` BadSignature; `nonce != nonce(from)` BadNonce; `amount + fee` overflowing or above
  `balance(from)` InsufficientFunds. Then debit `amount + fee` from `from` and add 1 to its nonce,
  credit `amount` to `to`, credit `fee` to `p`; a credit that overflows u64 is Overflow. `from ==
  to` is allowed.
- `append` checks in this order and returns the first failure, leaving the chain unchanged:
  `height != tip.height + 1` BadHeight; `parent != tip.hash()` BadParent; `time <= tip.time`
  BadTime; `proposer != expected_proposer()` WrongProposer; `!header.verify()` BadSignature;
  `txs.len() > MAX_TXS` TooLarge; `tx_root != merkle_root(tx encodings)` BadTxRoot; txs applied in
  order to a copy of the state, the first failure is `BadTx { index, error }`; `state_root` not the
  resulting root BadStateRoot. On success the block becomes the tip.
- `propose` builds the next block (height, parent, both roots, `time`, proposer =
  `public_key(seed)`, signed) without checking proposer or time; it fails only with `TooLarge` or
  the first `BadTx`.

## Tests required
`tests/aurum.rs`: the RFC 6962 test-vector roots, proofs for every index of trees of 1 to 40
leaves, tampered proofs rejected, tx and block encodings and round trips, decode errors, a chain
of blocks with random transfers checked against a simple model, every `append` error, and random
bytes never panicking the decoders.

## Extra check the leader will run
`crates/aurum/tests/seam_leader.rs`: its own Merkle, encoding, signing and state model built from
sphinx primitives; RFC 6962 vectors; proofs compared element by element; byte-exact tx, header and
block encodings; a 40-block chain built by the model and appended through `Block::decode`; an
invalid-block corpus (one defect per block, plus precedence pairs) each rejected with the exact
error and the chain unchanged; decoder fuzzing.

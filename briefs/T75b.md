## Demos (each: `src/demos/<id>.rs`, a `Demo` with a short `default_input`, pure, deterministic, bounded,
`Output::Text`, never panics on any input; input over `MAX_INPUT_BYTES` is an error)
| id | Input | Output |
|---|---|---|
| cobalt | Logos source | IR before and after `optimize` (with `Stats`), bytecode size, then `run_main` result |
| elysium | Logos source (compiled through cobalt) | the verified MBC1 module as a disassembly-style listing and its run result with step count |
| mercury | a raw HTTP/1.1 request (accept `\n` line ends, convert to `\r\n`) | parsed method, target, version, headers, body length, or the parse error; then a 200 response written by `write_response` |
| aurum | lines `from to amount` | a 3-block demo chain built with the demo keys: block hashes, Merkle root, one inclusion proof verified, final balances; a bad line gives an error naming it |
| argo | a small registry index and a manifest in one text (sections `[index]`, `[manifest]`) | the solved versions as a lock file, or the solver's conflict explanation |
| krypton | one shell line | the parse tree (indented), then each word after expansion with `X=7`, `HOME=/home/demo` set |
| calliope | first line a regex, rest the text | each match `line:col text`, match count; a bad regex gives its error |
| chronos | lines `write PATH TEXT`, `commit MSG`, `branch NAME`, `checkout NAME`, `log` | after each command its result: object ids (short), commit ids, log lines, tree listing |
| kairos | lines `task NAME WEIGHT WORK` and `cpus N` | a per-CPU timeline in ticks and each task's share against its weight |
| midas | lines `alloc SIZE`, `free N` (the N-th allocation) | after each step the buddy free lists per order and heap bytes in use; double free is an error, not a panic |

## API additions (exact)
```rust
// spelunk::style
pub enum Display { Block, Inline, None, Flex }     // `display: flex` is the one new value
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum FlexDir { Row, Column }
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum FlexJustify { Start, Center, End, SpaceBetween }
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum FlexAlign { Start, Center, End, Stretch }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Flex { pub dir: FlexDir, pub justify: FlexJustify, pub align: FlexAlign, pub grow: u32, pub gap: i32 }
pub fn compute_flex(doc: &Document) -> Vec<Option<Flex>>;   // Some for elements only
```
- Properties, same cascade as T66a, none inherit: `flex-direction` (row, column),
  `justify-content` (flex-start, center, flex-end, space-between), `align-items` (flex-start,
  center, flex-end, stretch), `flex-grow` (non-negative integer), `gap` (`Npx` or 0, negative
  clamps to 0). Initial: Row, Start, Stretch, 0, 0.
- `layout` gets the flex values by calling `compute_flex(doc)` itself.

## Flex layout (exact)
- A Flex element sits in its parent like a Block (same width, margins and stacking rules) and is
  reported in `boxes` like a Block. Its element children with display other than None are items,
  laid out as Blocks whatever their display, and reported in `boxes`. Text children of a flex
  container are not laid out. No margin collapsing inside a flex container; Auto margins are 0.
- **Row.** Item base outer width = margins + borders + padding + (`width` if fixed, else 0).
  Free = container content width - sum of base outer widths - gap * (n - 1). If free > 0 and the
  sum of `flex-grow` is above 0, each growing item's content width grows by `free * grow / sum`
  (floor), and the last growing item also takes the remainder; justify is then Start. Otherwise
  justify places items with the leftover free space (negative counts as 0): Start, Center (floor
  of half before the first item), End, SpaceBetween (spacing `free / (n - 1)` floor added to the
  gap, remainder unused; one item behaves as Start). Each item is then laid out at its width to
  get its natural border-box height. Line cross size = container `height` if fixed, else the max
  item outer height (0 for no items). Stretch items with Auto height get border-box height =
  cross - vertical margins (at least their padding + border); other items are placed at the top
  (Start), centre (floor) or bottom (End) of the line, by outer box. Container Auto height =
  cross size.
- **Column.** Items stack top to bottom with `gap` between them. Item widths: Stretch and Auto
  width fills the container content width minus horizontal margins; otherwise the fixed width,
  or 0 for Auto, placed Start / Center (floor) / End horizontally. Grow distributes free height
  only when the container has a fixed `height` (same rule as row, on heights); justify works on
  the leftover height the same way. Container Auto height = sum of outer heights + gaps.
- Saturating arithmetic everywhere; nothing panics on any document.

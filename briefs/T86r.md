## Build
- `Titan::boot_with_disk(elf_bytes, disk: Vec<u8>) -> Result<Titan, String>`: boots with the given hades image
  (checked: right size for the kernel's disk device, mounts, has `/etc/shell` or what the shell needs; else a clear
  error). `Titan::boot` becomes `boot_with_disk(elf, build_shell_disk()?)`.
- `Titan::disk_bytes(&self) -> Vec<u8>`: the guest disk as it is now (after the guest's writes reach it).
- Public `default_disk() -> Result<Vec<u8>, String>` (the current `build_shell_disk`).
- `titan boot --disk IMG`: loads IMG if it exists, else creates it from `default_disk()`; on exit (EOF, script end,
  or guest exit) writes the disk back atomically (temp file + rename). Without `--disk` nothing changes.

## Tests
`tests/disk.rs`: a file written by a shell command in one session is present after `disk_bytes` -> new session with
`boot_with_disk`; a wrong-size or garbage image is an error, not a panic. CLI test: two `titan boot --disk` runs with
scripts, the second sees the first's file. Skip kernel-needing tests with a printed note if the kernel ELF is missing
(the way the existing tests do).

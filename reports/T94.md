# T94 midas safe Sim report
- Built `crates/midas/src/sim.rs`: `Sim::new(bytes) -> Result<Sim, SimError>` (owns a zeroed Vec arena, one page over-allocated, aligned by `Heap::init`), `alloc(size) -> Result<Handle, SimError>`, `free(Handle) -> Result<(), SimError>`, `block(Handle)`, `blocks() -> Vec<Block>` (offset, size, order, state Live|Freed), plus `total_bytes`, `used_bytes`, `check`.
- Errors: `ZeroSize`, `OutOfMemory`, `Foreign` (other Sim or never issued), `DoubleFree` (stale generation). Handles carry a per-Sim id and slot generation; nothing panics and the unsafe free is never reached for a dead or foreign handle.
- Outside sim.rs only additive: `lib.rs` (extern crate alloc, mod sim, re-exports); `heap.rs` makes four helpers `pub(crate)`. Existing APIs unchanged.
- Unsafe: two blocks in sim.rs (`Heap::init`, `Heap::dealloc`), each with a `// SAFETY:` comment.
- Tests: 4 unit tests in sim.rs; `tests/sim.rs` has a shadow-model property test (48 cases x 300 ops, overlap, blocks() vs model, check() each step) and refusal and cross-Sim tests.
- `cargo build -p midas --target wasm32-unknown-unknown` passes with the same CARGO_TARGET_DIR.
- Gate last line: `CHECK PASS midas`. Note: tools/check.sh exports its own CARGO_TARGET_DIR (target/w-midas), overriding the prefix.
- Not done: no Miri run; freed blocks stay listed in blocks() until their slot is reused.

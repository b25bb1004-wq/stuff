T74b (partial): debugger core in crates/athena, no UI yet. Files: src/debug.rs (Debugger: start, step, step_budget, select, state, text protocol, global session), src/wasm.rs (athena_debug_start/step/frame/stop), src/lib.rs (pub mod debug), Cargo.toml (path dep elysium), tests/debug.rs (15 tests), tests/wasm_build.rs (4 new exports required).
Protocol: start(src) pauses before main's first op; step mode 0 continue, 1 over, 2 into, 3 out; breakpoint lines = digit runs in the text at (bp_ptr, bp_len); records: status (paused|budget|done|trapped|error), line, col, selected, message, output, frame <i> <name> <line> (0 = innermost), var <name> <value>; \ \n \r escaped.
A Budget pause keeps the stepping anchor (mode, line, depth) in the session, so Over/Out survive many budget pauses (tested: same stop as an unbudgeted step).
Values print as Logos source: strings quoted, lists [1, 2, ...] cut at 8, depth 3, option none/some(x), records (a, b), bytes as numbers.
Caller lines use pc-1 (a caller's pc is the op after its call); cobalt maps the op after a returned call to the fn header line (probe: Over from `var x = work(300)` stops on the `fn main` line, same without budget), a cobalt issue to report to the cobalt owner.
Observed: var bindings are listed when live (node probe shows `var x 1`), which is more than the brief's parameters-only note; io.read_line always returns none.
Gate: CHECK PASS athena (fmt, clippy -D warnings, all tests, zero-dep). Pack built: target/athena-web. Node probe: 3-line main, breakpoint on line 3, Continue -> paused, line 3, col 10, frame main 3, var x 1.

# T75e: iris terminal traps on wasm32
- Cause: `krypton::exec::Shell::new` called `std::env::vars()`, which panics ("unsupported" env) on wasm32-unknown-unknown; the trap appeared in every `open terminal` script.
- Fix: crates/krypton/src/exec/mod.rs skips the environment import when `cfg!(target_family = "wasm")`; native behaviour unchanged.
- Node evidence (packed target/site-web/site.wasm): iris example 0 and 1 return PIXELS 640 400; example 2 returns error text "line 2: unknown command `warp`" (no trap).
- Gates: CHECK PASS krypton, CHECK PASS iris, CHECK PASS site (fmt --check, clippy -D warnings, tests, zero-dep).

# D3: calliope terminal editor and chronos commit editor

1. Built: `calliope [FILE]` (Windows console via kernel32 shim, Linux termios shim, not compiled or run on Linux here); pure session/render/input/file/syntax modules in the lib, tested without a console (22 + 20 tests in tests/terminal_tests.rs, all passing).
2. Editing: atomic save (temp + rename) keeps CRLF/LF/mixed and the trailing newline; invalid UTF-8 refused; undo/redo, Ctrl-S/Q (asks when dirty), Ctrl-F/N/P search with wrap, Ctrl-G, Shift+arrows, Ctrl-C/X/V internal clipboard, mouse click/drag/wheel, status line with [+] dirty mark.
3. Syntax: Rust and Markdown via a line-state tokenizer; `.lg`/`.logos` via the existing Logos highlighter, applied per line.
4. 10 MB timings (debug build, `cargo test -p calliope --test terminal_tests -- --nocapture`): open+first frame 90.6 ms; jump to last line 0.2 ms; typing 100 keys at the end with a frame each 648 ms total (6.5 ms/key); 50 wheel steps 11 ms; save 9 ms, round-trips byte-identical.
5. chronos commit without -m opens $EDITOR (or calliope), drops `#` lines, aborts on empty; checked by hand in a scratch repo (editor message committed; empty aborted, exit 1); -m path unchanged.
6. Old tests untouched and passing; unsafe confined to src/bin/calliope/tty.rs with SAFETY lines; check.sh not edited; zero external crates.
7. Gaps: Linux shim untested; one file per session (extra FILE args ignored with a notice); undo back to the saved state still shows modified; no SIGWINCH redraw until next key; wide/non-BMP characters count as one cell and Windows surrogate pairs are dropped; no save-as; Logos multi-line tokens approximate.
8. Gates: `bash tools/check.sh calliope` and `bash tools/check.sh chronos` both end CHECK PASS on the final code; nothing committed.

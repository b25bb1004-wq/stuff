# T86r Report: `neon` disk images and `titan boot --disk IMG`

- API (`crates/neon/src/session.rs`): added `Titan::boot_with_disk(elf_bytes, disk: Vec<u8>)`, `Titan::disk_bytes(&self) -> Vec<u8>`, and `pub fn default_disk() -> Result<Vec<u8>, String>`; `Titan::boot` delegates to `boot_with_disk(elf_bytes, default_disk()?)`; validates non-empty block-aligned size, `hades::Fs::mount`, and `/etc/shell` file presence.
- CLI (`crates/neon/src/bin/titan.rs`): added `boot --disk IMG` (loads `IMG` or initializes with `default_disk()` when missing, atomically writes temp file + `sync_all` + `rename` on EOF, script end, or guest exit; leaves `--disk`-less behavior unchanged).
- Tests: added `boot_with_disk_rejects_invalid_images` in `crates/neon/src/session.rs`, 3 tests in `crates/neon/tests/disk.rs`, and `boot_disk_persists_across_runs_and_rejects_bad_image` (plus updated `--disk` usage check) in `crates/neon/tests/cli_titan.rs` (4 new tests + 1 updated).

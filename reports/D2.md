Strata import: 265 commits (the brief said 600+; the repo has 265), 1 branch, 0 tags, into an empty scratch dir outside the repo; import took 20.6 s (debug build, Windows).
Head tree: 1672/1672 files match `git ls-tree -r HEAD` (paths, blob SHA-1, mode); status clean after import.
Export: tested on a throwaway clone of strata: new commit has the right author, date and message, status is clean, a second export is a no-op, and a dirty checked-out branch is refused before anything is written.
Tests: crates/chronos/tests/git_bridge.rs (3 tests: per-commit tree and metadata vs git on a repo with branches, merge, rename, binary, exec bit, tags, non-ASCII message; import idempotence and export round trip; dirty refusal). Without a git binary they print SKIPPED to stderr.
Verbs: status, add (files or directories), commit (author from CHRONOS_NAME/CHRONOS_EMAIL, else git user.name/user.email), log, branch, switch (alias of checkout), diff (staged vs HEAD, same set as status; unstaged edits show only after add).
Gaps: annotated tags become plain refs (tagger and message lost); notes and remote-tracking refs are not imported; symlinks, submodules and Windows-unsafe names are refused; `chronos log | head` panics on a closed pipe (pre-existing println!).

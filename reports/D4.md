# D4: one-command install of the Monolith tools

Result: 27 tools build, copy and run from a temp home. 23 of 27 pass `--help` with exit 0. 4 fail in the crates (not the installer): bench, iridium-cli, logos, pandora. Crates were not touched.

1. Bin targets in the workspace: 36 (from `cargo metadata --no-deps`). Installed: 27.
2. Skipped, with reason: deploy `argo-registry`, `aurum-node`, `iridium-server`, `monolith-web` (servers needing setup); deploy `healthcheck` (container probe); zeus `zeus` and titan `kernel`/`userland` (no_std images, empty stubs on a host); silicon crate `silicon` (same bin name as chisel's `silicon`, which is the one installed). Examples and tests are not bins, so not listed.
3. `tools/install.sh` (Linux, Git Bash): `bash -n` passes. Builds the 27 tools with one `cargo build --release`, copies via a sibling file and rename, writes `VERSION` (git short sha, here 94fe550) and `MANIFEST` (tool, one-line `--help` summary). Default leaves PATH alone and prints the line. `--add-to-path` appends one marked line to `~/.profile`. `--uninstall` removes the bin folder, VERSION, MANIFEST, and the marked line.
4. `tools/install.ps1` (Windows PowerShell 5.1): parses; `-WhatIf` dry run changes nothing; a real run with USERPROFILE redirected to a scratch folder installed 27 tools, and `-Uninstall` removed them. `-AddToPath` sets the USER Path only and refuses if the entry exists. Reports tools still running the old build, and tools whose file cannot be replaced (NOT UPDATED, exit 1), both tested with a running stand-in.
5. Upgrade in place tested: the second sh run replaced all 27 files and the MANIFEST without error.
6. Not tested, by instruction: `--add-to-path` and `-AddToPath` (never run). The Windows Terminal settings were not touched; the profile snippet is in `docs/DAILY.md` under Packaging.
7. The sh script does not detect running tools. On Git Bash a running `krypton.exe` was replaced without error (Windows allows the rename), so the old build stays in memory until restart. The ps1 script reports this case.
8. Crate fixes needed (out of D4 scope): `bench`, `logos` and `pandora` reject `--help`; `iridium-cli` treats `--help` as an address; `pandora` exits 125 on `--help`.
9. `VERSION` is the plain sha, with no dirty flag, so a build from a dirty tree reports the last commit.
10. Changed files: `tools/install.sh`, `tools/install.ps1`, `docs/DAILY.md` (Packaging line and new section), `reports/D4.md`. Nothing committed.

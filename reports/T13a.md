# T13a quartz (RV64IMAC: A and C extensions)
- Added `AmoOp` and `LrW`/`LrD`/`ScW`/`ScD`/`AmoW`/`AmoD` variants to `quartz::inst` (`decode`, `encode`), rejecting `LR` with `rs2 != 0`.
- Added `decode_c(h: u16) -> Option<Inst>` for all 33 RV64C forms in `inst/decode_c.rs`, rejecting reserved and FP encodings.
- Updated `exec.rs` and `csr.rs` for IALIGN=16 (`check_pc` bit 0, `mepc`/`sepc` clear bit 0, `misa` adds A+C, 16/32-bit fetch with second-half fault tval).
- Added `amo.rs` and `Cpu::reservation` (cleared on every SC and on trap entry in `trap.rs`), with `.W` sign-extension, `Access::Store` for AMO/SC, and `Access::Load` for LR.
- Updated 3 IALIGN=32 assertions (`tests/csr.rs`, `tests/exec.rs`, `tests/priv_props.rs`) for IALIGN=16 (`xepc & !1` and legal `2 mod 4` targets).
- Added `tests/c_ext.rs` (8 tests: exhaustive u16 fuzz, all 33 forms, reserved forms, straddling fetch, `Machine` mixed program) and `tests/a_ext.rs` (5 tests: `forall` round trips, all 9 AMOs W/D, MMIO bus trace, LR/SC + trap clearing, faults).
- Gate: `bash tools/check.sh quartz` -> `CHECK PASS quartz`
- Tests: 124 passed, 0 failed (plus `cargo clippy -p quartz --all-targets -- -D warnings` clean).
- Missing/uncertain: None; LLVM cross-check (`tests/ac_leader.rs`) is reserved for the leader.

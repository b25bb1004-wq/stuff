What zeus is

Zeus is a type-1 hypervisor. It runs in the hypervisor mode of Silicon's RISC-V H extension, one level below the guests. It gives each guest its own memory space, takes turns running the guests round-robin, and emulates the devices they touch, such as the UART, the timer and the test finisher. The guests in this build are lithium, a small assembly kernel, and titan, a Rust kernel with its own processes.

This page does not run zeus in the browser. Zeus is an RV64 program, and the site bundle carries no built copy of it, so the console output below is a recorded run, not a live one.

Run it

cargo run -p zeus --example two_guests --release
zeusctl run --guest lithium:4 --guest titan:16 --steps 80000000

The example builds zeus and titan for riscv64gc-unknown-none-elf, boots both guests and prints each guest's console with a name prefix. Up to three guests fit, each in its own slot of guest RAM.

CLI usage

zeusctl - Boot and inspect guests under the zeus hypervisor on Silicon

USAGE:
    zeusctl <COMMAND> [OPTIONS]
    zeusctl --help
    zeusctl --version

COMMANDS:
    run     Boot zeus with one or more guests and print per-source console output

OPTIONS (run):
    --zeus PATH         Path to zeus RV64 ELF
                        [default: target/zeus-bin/riscv64gc-unknown-none-elf/release/zeus]
    --guest NAME[:MiB]  Guest to boot: lithium (default 4 MiB) or titan (default 16 MiB);
                        repeatable up to 3 guests, even MiB in 2..=16
                        [default: lithium:4]
    --titan PATH        Path to titan RV64 kernel ELF
                        [default: target/titan-kernel/riscv64gc-unknown-none-elf/release/kernel]
    --steps N           Maximum Silicon steps to execute [default: 20000000]
    -h, --help          Print help

EXAMPLES:
    zeusctl run
    zeusctl run --guest lithium:4 --guest titan:16 --steps 80000000

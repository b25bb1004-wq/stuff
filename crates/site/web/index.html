The 25 systems

  • Titan Rust no_std kernel + userland on the Monolith CPU. The thick layer everything rides on.
  • Iridium Paged B+tree, write-ahead log, SQL subset, server. A layer of sediment laid down in order.
  • Elysium Bytecode VM with garbage collector. A sealed world inside a plain rock.
  • Mercury HTTP/1.1 server on our own thread pool. Where the rock breaks the surface and the world can see it.
  • Helios ECS, software renderer, physics, audio. The thing that moves worlds.
  • Cobalt Logos to RV64 machine code and to bytecode. Sintering fuses loose powder into solid metal.
  • Logos Lexer, parser, type checker, IR. Logos splits into perfect thin layers, like its effect system.
  • Odyssey HTML + CSS parser, layout, paint. Spelunking is exploring caves.
  • Aurum Proof-of-stake chain, contracts on Elysium, stored in Iridium. One unbroken vein of ore.
  • Sphinx + Medusa Sphinx: standard primitives proven on vectors. Medusa: our own experimental cipher, never the default.
  • Silicon RV64 emulator with MMU, traps, devices. The crystal that keeps time for every real processor.
  • Hades Journaled, checksummed, extent-based. Hades splits into flat pages.
  • Pandora Linux namespaces, cgroups v2, pivot_root. A small sealed cavity in rock.
  • Argo Signed packages, version solver, registry. A stack of stones that marks the trail.
  • Krypton POSIX-style shell. The outermost shell of the planet.
  • Iris Compositing window manager. Each window is one face of the cut stone.
  • Indium Widgets, layout, text, animation. What a polished surface gives back.
  • Calliope Rope-based modal editor. The first thing people wrote on.
  • Athena Browser IDE: editor + compiler + emulator + debugger. The workshop where stones are cut.
  • Chronos Content-addressed commits, branches, 3-way merge. A core sample is history you can read layer by layer.
  • Xenon Encrypted reliable transport over UDP. Signals that travel through the earth.
  • Lithium A small kernel in pure RV64 assembly. Small, hard, makes the first spark.
  • Kairos Fair scheduler core + work-stealing pool. Erupts on schedule.
  • Midas Buddy + slab allocator. Where blocks are cut.
  • Zeus Type-1 hypervisor on the H extension. Nothing sits lower.
